## 1. 常規 vs 暑期：收費節奏

| | 常規學年（約九至六月，`YYZZ`／`regular`） | 暑期（`*SM`／`summer_two_period`） |
| --- | --- | --- |
| 報讀 | 默認讀至學年結束（或單堂） | 第一期／第二期／兩期全報／單堂 |
| 學費實務 | **按月**繳交；常見一次約 **4 堂**＝一個月 | 開課前按所報範圍**一次收齊** |
| 本檔逾期罰款 | **適用**（常規專科班） | **不適用** |

### 與系統收款工具的對應（現況）

- **收款登記**：`/Payments`；UI 預設一次收 4 堂——對齊常規「一個月」慣例。
- **每月學費**（`/MonthlyTuition`）：**已下線**；常規學費以已繳堂數＋`/Payments` 為準。
- **追學費（堂數缺口）**：RPC／阿Po 仍可查「已扣堂數 ≥ 已繳堂數」；**唔等於**本檔逾期罰款規則。

## 2. 逾期罰款（定案摘要）

詳細例子、豁免、家長說法見**前線指引**。工程對齊時以該指引＋本節為準。

| 項目 | 規則 |
| --- | --- |
| 金額 | 每科每次 **HK$50** |
| 判定 | 該生該班**已繳堂數** vs **已扣堂數**（點名計費白名單）；拖欠則收款時加罰 |
| 次數 | **同一學生 × 同一科 × 同一曆月最多一次**；月月遲交則月月可罰 |
| 優惠 | **不適用於罰款** |
| 試堂 | **不罰**；試堂出席不作為正式學費拖欠依據 |
| 私人課程 | **不罰** |
| 功課輔導班 | **不罰**（月費見 [`HOMEWORK_TUTORING_MONTHLY_FEE.md`](HOMEWORK_TUTORING_MONTHLY_FEE.md)） |
| 暑期 | **不罰** |
| 單據結構 | 繳費／優惠／罰款／備註分開；罰款不增加已繳堂數 |
| 豁免 | 須原因；豁免仍計入「該月已處理」，並可統計 |

### 禁止入室

補習社口頭規則或仍提及嚴重遲交不宜入室。
**系統不做**禁止入室警示或門禁；前線罰款執行**不與**禁止入室綁成同一套自動程序。

### 與舊「曆月第 N 堂」表述

舊文曾寫「該曆月第 2 堂仍未交 → $50」。  
**現行執行與系統化口徑**改為已繳堂數不足＋每月每科一次（見前線指引）。政策對外解說以前線指引為準。
