# 收款單據作廢與更正 — 營運政策

介面用語：**繁體中文**。  
性質：**營運政策**（系統已強制禁硬刪；跟進報讀仍靠人手）。索引見 [`OPS_POLICIES.md`](../_INDEX.md)。  
產品定案表：[`backlog/summer-enrollment-roster-consistency.md`](backlog/summer-enrollment-roster-consistency.md) §4.13／G2。  
操作畫面：作廢見 [`manual/PAYMENT_RECEIPTS.md`](../../playbooks/frontdesk/PAYMENT_RECEIPTS.md) §7；已繳堂數調動見後台 **「單據／權益更正」**（`/PaymentCorrection`）。

**產品定案：** 2026-08-09（時間窗／第二人）；全文對齊 §4.13：2026-08-11。2026-11-13：外星人不論開單多久，本人即可作廢。  
**系統現況：** 禁硬刪、作廢密碼＋原因。外星人一人、不論時長。前台行政仍為 ≤30 分自行作廢、>30 分第二人。已繳堂數調動表與「權益更正」頁已推出。作廢後自動退讀等仍靠人手（§5）。

---

## 1. 一句話

**單據不可硬刪。開錯不等於一律作廢——先分錯類型：堂數或科班錯誤走已繳堂數調動；金額或優惠錯誤、重複單等走作廢（必要時重開）。外星人可自行作廢，不論開單多久；前台行政在 30 分鐘內可自行作廢，逾時須第二人確認。**

---

## 2. 兩類唔好撈亂

| 類 | 意思 | 主路徑 |
| --- | --- | --- |
| **A. 單據錯誤** | 單開錯／要改錢或改單 | 按下方分流：已繳堂數調動 **或** 作廢（±重開） |
| **B. 已繳堂數轉讓／搬移** | 堂應喺邊個學生／邊個科班（例如轉科、唔退款送親友） | **唔當開錯單**；用已繳堂數調動搬堂；錢單是否重開另計 |

「收錯學生（真係開錯單）」屬 **A**；「學生唔再讀、堂送親友」屬 **B**——分開入口，唔好當同一件事。

---

## 3. 按錯類型點處理（A 類）

| 情況 | 做法 |
| --- | --- |
| **堂數填錯**（G2a） | **唔一定作廢**。只調回／clawback **未耗**堂數；寫入已繳堂數調動原因。入口：單據／「權益更正」頁。 |
| **科目／班收錯**（G2b） | **唔作廢收據**。用已繳堂數調動把堂搬去正確科班（同表留痕）。`2627` 同一級專科小組已共用餘額，同組別搬堂通常唔使。 |
| **金額／優惠錯、堂數啱**（G2d） | **作廢＋重開正確單**（唔靠改原單金額）。已繳堂數可短暫為負數。 |
| **支付方式錯；或狀態誤觸**（G2e） | 只改支付欄；若誤觸已繳堂數入帳則 clawback。一般**唔作廢整張單**。 |
| **重複收款**（G2f） | 作廢多出嗰張。若已耗超過「留低嗰張」可覆蓋 → **拒整單作廢**，或只 clawback 未耗。 |
| **收錯學生（開錯單）** | 未耗：可作廢／clawback。已耗：拒整單或先處理點名。**唔等同**「送親友」調動已繳堂數。 |

總則：**已消耗堂數 > 作廢後應留堂 → 拒作廢**（或只處理未耗部分）。

---

## 4. 何時作廢、誰可作廢

### 4.1 仍有效原則

- 已開出的繳費／收款單據屬**金錢與對帳憑證**，**禁止硬刪**（保留稽核，防「刪單消帳」）。
- 需要作廢時：保留原單與操作紀錄；若錢或項目不對，另開正確新單。

### 4.2 角色與確認

| 項目 | 規則 |
| --- | --- |
| 角色 | 僅前台行政與外星人可作廢；專班老師無收款頁。已繳堂數調動頁另開放管理層（見系統畫面）。 |
| 基本確認 | 作廢須再輸入自己的登入密碼，並填寫作廢原因 |
| 外星人 | 不論開單多久，本人密碼與原因即可作廢，不需第二人 |
| 前台行政，開單 ≤30 分鐘 | 本人密碼與原因即可作廢 |
| 前台行政，開單 >30 分鐘 | 另需管理層或外星人第二人確認（不可與操作者相同） |
| 學年 | 受學年編輯鎖限制（與其他繳費寫入相同）。外星人不受此鎖。 |

---

## 5. 作廢後系統會做什麼

| 項目 | 行為 |
| --- | --- |
| 單據 | 狀態改「作廢」；**單號保留、不重用** |
| 已繳堂數 | 對應學費入帳做 clawback（可短暫為負數） |
| 已繳堂數／營收統計 | 不再計入該單（只認「已收款」） |
| 轉介回贈 | pending 會取消 |
| 月費帳期 | 對應 charge 回滾／作廢，以便可重開同月 |
| 收件匣 | **系統通知**給 admin／alien（老師看不到）；內文含跟進提示 |
| 電郵 | 僅原狀態為**已收款**時，通知指定管理層電郵（寄信失敗不阻斷作廢） |

## 6. 作廢後前台必須人手跟進（系統不做）

**作廢 ≠ 退班。** 報讀與收款分開；作廢後學生可能仍「就讀中」、點名紙仍有人，但對帳可能顯示欠費／追收。

作廢成功後請立刻：

1. 決定該生是否仍應就讀 → 不應則**結束報讀**；應就讀則**另開正確新單**收款（G2d 等）。  
2. 查看堂數對帳、繳費紀錄是否合理。  
3. 若屬試堂轉正式一併收費：仍視為**正式報讀但該筆未付款**；僅家長不讀時才另退讀。  
4. 同批手足／同伴是否也要作廢、調整已繳堂數或重開單。
5. 告知家長：舊收據無效；以新單為準（單號不同）。

收到收件匣「單據已作廢」系統通知時，視同提醒完成上述檢查。

**已繳堂數調動（唔作廢）後：** 核對來源／目標科班的已繳堂數與點名是否合理；唔使當「舊收據無效」，除非另有作廢。

## 8. 系統現況摘要

- **已系統強制：** 禁硬刪；作廢須密碼與原因；外星人一人、不論時長；前台行政 ≤30 分自行作廢、>30 分管理層或外星人第二人；audit；收件匣通知；已收款可另發電郵；作廢 clawback；單據／權益更正頁（已繳堂數調動）。
- **尚未自動化：** 作廢後自動退讀／改試堂 outcome／改註冊狀態（有意保留；靠 §6 人手）。  
- **Resend 寄信：** 須已設定 API key／寄件網域；未設定時作廢仍成功，畫面／流程會提示通知未送出。

## 9. 舊說法（作廢）

以下**不再**是本社正確做法（僅留作對照）：

- 「單據開錯 → 一律必須作廢／不可用其他方式更正」
- 「已確認單不可改＝只准作廢」（忽略堂數／科班錯應走已繳堂數調動）
- 「任何人都可作廢，且一律無時間窗、無第二人確認」（2026-11-13 起：僅外星人一人、不論時長；前台行政仍限 30 分鐘內自行作廢）
