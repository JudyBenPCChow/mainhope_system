## 1. 通用規則（專科班）

| 項目 | 規則 |
| --- | --- |
| 適用 | 常規學年**專科班**上課校曆（非暑期、非功輔獨立月曆） |
| 結構 | 學年分多「期」；**每一期 × 每一星期幾（日–六）= 4 堂** |
| 「約每月 4 堂」 | 收費／對外慣例；**曆月**內某 weekday 的實際堂數可因月份日數與校舍假期而 **≠ 4**，唔等於排錯 |
| 校舍假期 | 表列日子本社沒有任何課堂；該日**不**出現在專科班上課日 |
| 公眾假期惟課堂如常 | 若校曆標示「公眾假期，惟課堂如常」→ **照常上課**；無故缺席不作補堂 |
| **重陽** | **正日放假、翌日不放假**。校舍假跟重陽**正日**；若政府將公眾假期訂於翌日，翌日仍可上課（屬「公眾假期，惟課堂如常」口徑） |
| 學年 start_date | 字典常為 9/1；**不等於**每一班／每一 weekday 的第一堂一定在 9/1 |

## 4. 2627 專科 vs 功輔：相異一覽

對照基準：§2 專科（附件原文）校舍假／首尾；§3 功輔已簽收開放日。  
「專科可上」＝該日**非**專科校舍假（若該 weekday 有班則可上課；公眾假「課堂如常」計入可上）。

### 4.1 首尾

| | 專科 | 功輔 |
| --- | --- | --- |
| 首日 | 2026-09-01 | 2026-09-01（相同） |
| 尾日 | **2027-06-28** | **2027-06-30** |

→ **2027-06-29、2027-06-30**：功輔仍開放；專科已完課（無對應期堂）。

| 2026-12-22 | 二 | 專科聖誕假自 12/25 起；功輔自 12/22 起放 |
| 2026-12-23 | 三 | 同上 |
| 2026-12-24 | 四 | 同上 |
| 2027-03-26 | 五 | 耶穌受難節：專科「課堂如常」；功輔納入復活假 |
| 2027-03-27 | 六 | 專科復活假僅 3/29–30；功輔 3/26–30 |

僅學年末例外見 §4.1（6/29–30 專科已完課、非校舍假表內日子）。
