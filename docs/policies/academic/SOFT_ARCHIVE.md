# 軟封存與查詢範圍

介面用語：**繁體中文**。  
性質：**營運政策**（補習社規則）。索引見 [`OPS_POLICIES.md`](../_INDEX.md)。  
機構自稱：見 [`TERMINOLOGY.md`](../../meta/TERMINOLOGY.md)（**明學教育**）。

**產品定案：** 2026-08-01（設計＋對抗通過）；2026-08-29 波次 1–7 系統化完成。  
**系統現況：** 政策已定。學年雙層窗 helper 已落地（暑期目前學年含下一常規）。學生管理列表預設不載入已畢業生（可開關顯示）；請假／試堂新增名單同樣預設排除。請假管理／試堂列表／增退管理頁跟日常營運窗（待處理請假／未完成試堂豁免年份窗；班別學年空白或增退空白生效日仍顯示）。班別管理預設日常營運窗（可「顯示」更舊學年；學年空白仍顯示）；新增排程／試堂／前台報讀班別名單同樣跟窗。排程日曆仍按所選日期範圍載入（舊日點名深連結仍通）。Inbox 維持約 30 日短窗。堂數對帳預設日常營運窗（待補／請假待安排仍顯示）。繳費紀錄預設日常營運窗並隱藏作廢單；匯出全部（核數）可出庫內全部。營運總覽標示日期區間與堂數不符範圍。標已畢業前會列出未清繳費／待補堂／未處理請假／就讀中報讀，可強制但須二次確認並寫入稽核。設定頁可關閉本機日常名單收窄。庫內資料永不因本政策刪除。

---

## 1. 一句話

**已畢業學生與超過約兩個常規學年的營運資料，日常名單預設不載入；不是刪除。單據、學生詳細頁、繳費匯出與核數仍可查庫內全部紀錄。**

---

## 2. 原則

| # | 規則 |
| --- | --- |
| 1 | **永不 DELETE**。軟封存只改變日常查詢預設範圍 |
| 2 | **封存學生**＝學業階段為「已畢業」（中學畢業）。**不是**非活躍、非在讀、或「停讀一段」 |
| 3 | 中一停讀、其後中五再報讀且未標已畢業者，必須留在日常名單 |
| 4 | **日常營運窗**約兩個常規學年（連帶其間暑期）；**合規／財務窗**為庫內全量或自選更長範圍 |
| 5 | 已知 id 的深連結（學生、班別、繳費單、舊日點名）必須仍可開啟 |
| 6 | 未完成的請假／待補、待確認繳費、待處理推薦回贈，不得因年份窗從待辦消失 |
| 7 | 對帳與管理總覽數字若收窄，必須標示資料範圍 |

### 2.1 為何不是刪除

稅務、核數、家長爭議與舊單據都需要歷史仍在庫。日常名單收窄是為減少負荷與雜訊，**不替代**保留或行銷同意政策。

### 2.2 雙層窗

| 層 | 用途 | 範圍 |
| --- | --- | --- |
| 日常營運窗 | 學生／班別／排程等教務列表預設 | 目前學年起往前，覆蓋兩個常規學年，並包含其前一個暑期。例：目前為 `2627` → `25SM`、`2526`、`26SM`、`2627`。目前為暑期（例 `26SM`）時，另含緊接的下一個常規學年（`2627`），以便暑假已開的下一學年班仍在日常窗。 |
| 合規／財務窗 | 繳費匯出、核數、dispute 查單 | 庫內不刪；可選全部或自訂學年。**不得**用日常窗做年結 |

學年時間序見 [`ACADEMIC_YEARS.md`](ACADEMIC_YEARS.md)。程式：`src/lib/softArchiveWindow.ts`。

財務匯出最短查閱年期：實作該入口前向會計確認；工程預設「庫內不刪、匯出可到全庫」。

## 3. 學生主檔

- 日常列表／搜尋／下拉預設排除 `academic_stage = 已畢業`（相容舊年級碼 `GD`）。
- 「顯示已畢業生」打開後才納入；學生詳細頁以 UUID 開啟者仍可讀。
- **禁止**用活躍狀態、在讀狀態、或「兩年無報讀」自動改為已畢業。
- 學號遞增必須掃描全庫（含已畢業）。見 [`STUDENT_CODE.md`](../enrollment/STUDENT_CODE.md)。

學業階段定義見 [`STUDENT_STATUS_CLASSIFICATION.md`](../enrollment/STUDENT_STATUS_CLASSIFICATION.md)。

標為已畢業前，系統會列出未清繳費、待補堂、未處理請假、就讀中報讀。預設**不是硬擋**：仍可強制畢業，但須二次確認（輸入「強制畢業」）並寫入稽核。改回「中學階段」即還原日常名單。

## 4. 上線體感

- 列表頂提示：「已隱藏 N 位已畢業生（資料仍在）｜顯示」。
- 班別管理：「已隱藏 N 個更舊學年班別（資料仍在）｜顯示」。學年篩選選到窗外學年時會一併載入。
- 堂數對帳／繳費紀錄：預設日常營運窗；待辦豁免；作廢單預設藏。營運總覽標示日期與對帳範圍。核數用繳費「匯出全部」。
- 行銷／舊生匯出可預設包含已畢業，與行政學生管理預設分開（完整校友模組不納入本期）。
- 緊急回滾查詢收窄：設定頁「日常名單收窄」改為全量載入（僅本瀏覽器）；或直接設 `localStorage.mgmt_soft_archive_queries = "0"`。
