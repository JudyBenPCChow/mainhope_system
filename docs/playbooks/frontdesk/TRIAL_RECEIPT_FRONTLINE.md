## 1. 一句話總則

**試堂一定要先出學費單並確認（含 $0）；確認後先有已繳堂數、先上點名紙。** 未出單或未確認：不上紙、不入已繳堂數。計唔計老師人頭，與收唔收錢、入唔入堂數分開，每次手選，無預設。

---

## 2. 從哪裡操作

| 步驟 | 入口 |
| --- | --- |
| 登記試堂 | `/TrialSessions` 試堂紀錄，或前台精靈「只登記試堂」 |
| 出單／確認 | `/Payments` 收款登記（試堂頁不負責收錢） |
| 點名 | `/Attendance` 或排程「確定點名」 |
| 老師得知 | 收件匣營運通知（確認收款後） |

建立試堂後系統會轉到收款登記（免費亦出 $0 單）。半價試堂選「半價試堂（正價＋50% 優惠）」。

---

## 3. 三種常見情況

### 3.1 全價試堂

1. 建立試堂（學生、班、堂次；手選是否計人頭）。
2. 收款登記：金額＝該堂正價；堂數＝1（連堂按實際節數）。
3. 確認收款後，當日點名紙見名，標「試堂」。

### 3.2 半價試堂

同上，但學費行填**正價**，再用優惠 **試堂半價（50%）** 扣至實收。不要只把金額改成半價而不留正價。

### 3.3 免費試堂

一樣出學費單：折實 **$0**、堂數填 **1**（沒有「純觀摩／堂數 0」）。畫面仍走現行收據流程；事實上不用向家長收款，最多不列印收據。確認後才上點名紙。

---

## 4. 點名紙與人頭

| 項目 | 說明 |
| --- | --- |
| 有無名 | 確認出單後才有（不論全價／半價／$0） |
| 標示 | 點名紙標「試堂」，與就讀生分開 |
| 計人頭 | 建立時手選；人數與計糧跟此旗標。計人頭不等於有沒有交錢 |

老師會在收件匣收到「試堂」通知（該堂實際授課老師／任教老師），內容含日期與計／唔計人頭。

---

## 5. 轉正與流失

- 學費只經收款登記；試堂頁不內嵌收錢。
- 未點名仍可轉正式報讀，但畫面會警告學費與出席可能對不上，應盡快完成點名。
- 流失須先取消試堂再登記原因。跨班轉正時，原試堂標已轉正並歸因到新報讀。

---

## 6. 不要做

- 試堂不出單就當免費完事
- 未確認就當學生已在點名紙上
- 半價只填半價實收、不留正價
- 假設有交錢＝一定計人頭（或相反）
- 在試堂頁、報讀頁或前台精靈內嵌收錢
