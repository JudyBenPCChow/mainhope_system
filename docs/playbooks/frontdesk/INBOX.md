# 收件匣

> 狀態：**現行**（營運通知＋系統通知；側欄底部捷徑含未讀火圖示）。
> 路徑：`/Inbox`  
> 側欄：日常工作 → 收件匣；另於「你登入為…」**上方**固定捷徑（全角色）

本文說明收件匣**現況用法**與可見事件目錄，供營運與開發對齊。

---

## 1. 功能簡介

收件匣分為兩個分頁：

| 分頁 | 說明 |
| --- | --- |
| **營運通知** | 排程／班別變動、增退讀、請假、點名提醒等日常營運訊息 |
| **系統通知** | 功能更新與選項變更（例如繳費方式調整） |

| 能力 | 說明 |
| --- | --- |
| 列表與篩選 | 近約 30 日；營運可依類型、只看未讀篩選 |
| 詳情 | 點列或「查看」開詳情；**開啟時自動標記已讀**；可前往相關頁 |
| 已讀狀態 | 每人獨立（老師依老師身分；員工依角色與顯示名稱） |
| 系統發佈 | **僅外星人**可發佈；可選「全部人」或指定角色（行政／外星人／老師） |
| 側欄未讀 | 「你登入為」上方收件匣捷徑；有未讀時顯示火圖示 |

角色：`admin`／`alien`／`teacher` 皆可進入。系統通知依發佈時指定的可見對象顯示。  
預設分頁：**行政**開收件匣先顯示**系統通知**（營運需另切）；老師／外星人仍預設**營運通知**。

---

## 2. 從哪裡操作

1. 側欄底部 **收件匣**（「你登入為…」上方；全角色）。
2. 或側欄 **日常工作 → 收件匣**／**所有功能**。
3. Admin／Alien 首頁快速入口亦可能有收件匣。

頁面操作：

- **營運通知／系統通知**：頂部分頁切換。
- **類型**（僅營運）：下拉篩選。
- **只看未讀**／**全部已讀**／**重新整理**。
- 外星人於系統分頁可 **發佈系統通知**（標題、內容、可見對象、相關路徑）。

---

## 3. 老師收件匣事件目錄（營運）

原則：

- **有完整新增／專用 log 的操作**（請假、增退讀等）→ 直接讀業務表進匣。
- **既有列上的局部修改且無變更 log**（代堂、任教老師變更等）→ 操作時寫入通知快照（`inbox_events`，category=`ops`）。
- **尚未點名** → 非操作，依現況推導待辦。

### 3.1 第一波核心（A）

| 事件 | 進法 | 老師為何看得到 |
| --- | --- | --- |
| 學生請假 | 讀 `leave_makeup_records` | 請假班別由其任教 |
| 新增報讀／退讀 | 讀 `enrollment_change_events` | 該班由其任教 |
| 指派／取消代堂 | 通知快照 | 原任或代堂老師在受眾內 |
| 排程取消／重大變動（日期、時間、當日老師） | 通知快照 | 實際授課老師、相關老師或任教老師 |
| 班別任教老師／狀態變更 | 通知快照 | 原任或新任老師為本人 |
| 尚未點名 | 現況推導 | 其當日或近期未點名堂次 |

### 3.2 第二波（B，已接線）

| 事件 | 進法 | 說明 |
| --- | --- | --- |
| 排程新增（單堂／連堂） | 通知快照 | 該堂老師為本人；連堂合併一則 |
| 排程新增（批次／循環一對一） | 通知快照**摘要一則** | 避免多堂洗版 |
| 班別整批取消排程 | 通知快照摘要 | 該班相關老師 |
| 一對一更換任教老師 | 通知快照 | 原任／新任老師 |
| 報讀形式變更、選堂變更 | 讀增退讀事件 | 該班任教老師 |
| 補堂已排定 | 通知快照 | 該班任教老師（改補堂日／補堂排程時） |
| 老師請假日處理摘要 | 通知快照 | 請假老師與代堂老師；各堂代堂／取消仍另有單則 |

### 3.3 系統通知

| 項目 | 說明 |
| --- | --- |
| 類型 | `system_update`（Tag：系統更新） |
| 可見 | `audience_roles` 空＝全部人；否則僅列出之角色 |
| 發佈 | 外星人後台；工程發版亦可 INSERT（例如繳費方式更新首則、欠費入口精簡 `20260730013000_…`）；**作廢繳費單**由 `void-payment` 自動寫入（僅 admin／alien） |
| 老師 | 僅在「全部人」或可見對象含老師時出現於系統分頁 |

試堂、繳費待辦、課室預約待審等——**不進營運收件匣**（專頁處理）；功能上線說明可走系統通知。

---

## 4. 注意事項

- 通知寫入失敗**不阻斷**主流程；系統通知發佈失敗會顯示紅字並上報。
- 老師營運通知仍只見自己班／學生相關項目。
- 「尚未點名」會隨點名完成而消失或不再列為待辦。
- Schema：`category`、`audience_roles` 見 migration `20260729235000_inbox_system_notices.sql`（需套用後系統分頁才正常）。Portal 核准不再自動開待繳費／欠費入口通告見 `20260730013000_simplify_tuition_arrears_entrypoints.sql`。
