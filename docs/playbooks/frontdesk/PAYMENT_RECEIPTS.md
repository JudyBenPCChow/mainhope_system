# 繳費收據：列印／下載／傳送／更正／作廢

> 狀態：**目前已完成並上線**（接待可用）。  
> 路徑：收款登記 `/Payments`、繳費紀錄 `/PaymentHistory`、單據／權益更正 `/PaymentCorrection`；學生詳情亦可列印／作廢。  
> 營運政策（禁刪／分流規則）：[`PAYMENT_RECEIPT_VOID_POLICY.md`](../../policies/payments/PAYMENT_RECEIPT_VOID_POLICY.md)

本文說明收據相關功能的**現況用法**，供日後系統說明書擴充時對齊。規則以政策篇為準；本篇只寫點入、點按。

---

## 1. 功能簡介

系統可為每筆繳費單據產生**統一樣式的 A4 收據**（待收款與已收款同一版面；文案隨狀態略有不同）。

> **2026-07 更新：** 已停用新建「待繳費」收據式通知單。下期學費請用收款登記的「提醒繳付下期學費」（文字／WhatsApp）。歷史待繳費單仍可於繳費紀錄標記已收。

已完成能力包括：

| 能力 | 說明 |
| --- | --- |
| 品牌版面 | 明學 logo、社名、地址、電話、WhatsApp、網站 |
| 金額明細 | 各收費項目、堂數、項目小計、各項優惠扣減、折實價（非只顯示合計） |
| 單據編號 | 當日遞增序號（格式見下文）；資料庫有唯一限制，併發時會重試 |
| 預覽後列印 | 收款登記可先開「收據預覽」再列印 |
| 建立後列印 | 出單／收款表單可勾選「建立後開啟列印」 |
| PDF 下載 | 一鍵下載 `.pdf`（版面與預覽一致，含 logo）；可存至接待處 OneDrive「學生收據」資料夾（Chrome 首次需授權選資料夾） |
| WhatsApp | 產生 PDF 後開啟 WhatsApp，方便傳送給家長（需學生／家長電話） |
| 家長開通 QR | 收據上附該生專屬家長查閱開通連結／QR |
| 開錯分流 | 堂數／科班錯用已繳堂數調動；金額／優惠錯或重複單先作廢再重開（見 §7） |

角色：

| 頁 | 誰可入 |
| --- | --- |
| 收款登記 | 行政、外星人 |
| 繳費紀錄 | 行政、管理層、財務、外星人 |
| 單據／權益更正 | 行政、管理層、外星人 |
| 作廢 | 行政、外星人（逾時須管理層或外星人第二人確認） |

專班老師無收款頁。

### 1.1 對帳習慣（設計原則）

- **所有收款**都應經「收款登記」入帳；前台對帳以**繳費紀錄**為準——有收款就一定能在繳費紀錄搵到同一張單。
- **試堂、請假、報讀、前台精靈等頁面不負責收錢**；需要收費時跳到收款登記（可帶學生）。前台精靈「收款／出單」步驟只導去收款登記，唔再精靈入面出單。試堂三種價錢一律先出單再上點名紙，見 [`TRIAL_RECEIPT_FRONTLINE.md`](./TRIAL_RECEIPT_FRONTLINE.md)。
- 工程／UI 條文見 [`UI_DESIGN_INSTRUCTIONS.md` §15](../../meta/UI_DESIGN_INSTRUCTIONS.md)。

## 2. 從哪裡操作

### 2.1 收款登記（`/Payments`）

1. 選學生。若該生同時有專科與功輔，先揀**本單類型**（專科／私人／試堂，或功課輔導班月費）。
2. 專科：填項目與優惠。功輔：填覆蓋起始月份與月數（不填堂數、不套專科優惠）。
3. 選擇「登記已收」或「待收款」。
4. 可勾選 **建立後開啟列印**。
5. 成功後可開啟 **收據預覽**（畫面與列印／下載一致），再按「列印」。
6. 亦可使用「預覽／重印」再次開啟預覽。
7. 選好學生後可按 **提醒繳付下期學費**，以文字／WhatsApp 預填提醒（人手發送）。

### 2.2 繳費紀錄（`/PaymentHistory`）

1. 查詢歷史單據。
2. 列上或詳情可 **下載收據**（PDF）、**WhatsApp** 傳送。
3. 待繳單據可 **標記為已收款**；完成後可下載／WhatsApp（與新建收款同一套收據樣式）。
4. 列上「作廢」（見 §7.3）。

### 2.3 學生詳情 — 繳費分頁

- 可對該生單據執行 **列印**（直接開啟瀏覽器列印）。
- 可對該生單據執行 **作廢**。

### 2.4 單據／權益更正（`/PaymentCorrection`）

行政請到 **所有功能 → 報表與分析 → 單據／堂數更正**。此功能用來調整已繳堂數（增減或搬堂），**不可用來更改收據金額**。詳見 §7.2。

### 2.5 示範頁（已下線）

- 原 `/receipt-demo` 假資料預覽頁已下線；對版請用正式收款／繳費紀錄列印或下載。

## 3. 收據上會出現什麼

- **抬頭**：logo、地址、電話、WhatsApp、網站；右側「收據」標題與單據編號  
- **開首句**：已收為「茲收到下列款項︰」；未收為「茲開立下列應繳款項︰」  
- **學生資料**：姓名、學號、收款日期、繳費方式、整單備註  
- **明細表**：項目（課程／班別）、堂數、金額、項目備註（有則顯示）  
- **金額區**：合計（正價）→ 各優惠扣減 → 折實價  
- **家長開通**：專屬 QR／連結說明  

機構聯絡資料目前寫於程式設定（與官網一致）；換址／換電話需由工程更新後發版。

---

## 4. 單據編號

- 格式：`MX-{RC|INV}-YYYYMMDD-0001`（當日遞增；序號過長時寬度會自動加位）  
- `RC`：已收款類；`INV`：待繳／通知單類  
- 資料庫有 unique index；分配衝突時系統會重試

---

## 5. PDF 下載說明（接待處）

1. 按「下載收據」會產生與螢幕預覽相同版面的 PDF（技術上為將收據畫面轉成 PDF，以保留 logo 與排版）。  
2. **Chrome（建議）**：首次請選取 OneDrive 路徑「學生收據」資料夾並授權；之後可自動存入該資料夾。  
3. 其他瀏覽器或不支援資料夾授權時：改為一般瀏覽器下載。  
4. 學期資料夾名稱若更換（例如暑期／新學年），需由工程更新路徑提示，並請接待處重新選一次資料夾。

---

## 6. WhatsApp 傳送

1. 系統產生收據 PDF 並下載。  
2. 開啟 WhatsApp（需學生檔案有 WhatsApp／學生或家長電話）。  
3. 請在對話中**自行附加**剛下載的 PDF 後傳送。

## 7. 開錯單據與已繳堂數更正（禁止刪除）

**單據不可硬刪。開錯唔等於一律作廢。** 先分錯類型，再揀入口。

兩類唔好撈亂：

| 類 | 意思 | 主路徑 |
| --- | --- | --- |
| **A. 單據錯誤** | 單開錯／要改錢或改單 | 已繳堂數調動 **或** 作廢（必要時重開） |
| **B. 已繳堂數轉讓／搬移** | 堂應喺邊個學生／邊個科班（例如轉科、唔退款送親友） | **唔當開錯單**；用已繳堂數調動搬堂 |

「收錯學生（真係開錯單）」屬 **A**；「學生唔再讀、堂送親友」屬 **B**。

### 7.1 按錯類型點處理

| 情況 | 做法 | 入口 |
| --- | --- | --- |
| 堂數填錯 | 唔一定作廢。只調回未耗堂數，並寫明原因 | 單據／權益更正 →「單池增減」 |
| 科目／班收錯 | **唔作廢收據**。把已繳堂數搬去正確科班。同一級專科小組已共用餘額，同組別通常唔使搬 | 單據／權益更正 →「搬堂（兩池）」 |
| 金額／優惠錯、堂數啱 | **作廢＋重開正確單**（唔改原單金額） | 繳費紀錄作廢 → 收款登記重開 |
| 支付方式錯；或狀態誤觸 | 只改支付欄；若誤觸已繳堂數入帳則調回。一般**唔作廢整張單** | 繳費紀錄 |
| 重複收款 | 作廢多出嗰張。若已耗超過「留低嗰張」可覆蓋 → 系統可能拒整單作廢 | 繳費紀錄 |
| 收錯學生（開錯單） | 未耗：可作廢或調回。已耗：可能拒整單，或先處理點名。**唔等同**送親友 | 視情況：作廢或更正頁 |
| 堂送親友／轉讓 | 唔當開錯單。由來源學生搬去目標學生。雙方家長確認仍靠人手（系統未強制） | 單據／權益更正 →「搬堂（兩池）」 |

總則：**已消耗堂數 > 作廢後應留堂 → 系統拒作廢**（或只處理未耗部分）。

### 7.2 單據／權益更正（已繳堂數調動）

1. 行政開啟 **所有功能 → 報表與分析 → 單據／堂數更正**。
2. 先按「先揀錯咗咩」對應按鈕（會幫你切去單池增減或搬堂）。
3. 搜尋並選學生。畫面「權益池」＝該科**已繳堂數**餘額（班名 · 包裝 · 餘 N 堂）。
4. **單池增減：** 填調動堂數（負數＝減少未耗堂）→ 選原因 → **備註必填** →「確認調動」。
5. **搬堂（兩池）：** 選來源學生／已繳堂數 → 目標學生／已繳堂數 → 搬堂數 → 原因 → 備註 →「確認搬堂」。同一學生搬科班時，來源同目標都選該生即可。
6. 下方「近期調動紀錄」可核對時間、增減、調動前後餘額、原因、操作者。

調動成功後：核對來源／目標科班的已繳堂數與點名是否合理。**唔使當舊收據無效**，除非你另外作廢咗單。

金額／優惠錯請按頁內「作廢單據（金額錯）」去繳費紀錄，再「收款登記（重開）」另開正確新單。

### 7.3 作廢單據

只適用 §7.1 要走作廢嘅情況。不可直接刪除已確認單據。

**誰可操作**

- 行政、外星人
- 須再輸入**自己的登入密碼**，並填寫**作廢原因**（至少 2 字）
- 開單後 **≤30 分鐘**：上述即可
- 開單後 **>30 分鐘**：另要 **管理層或外星人** 輸入電郵與密碼作第二確認（不可同操作者本人）
- 受學年編輯鎖限制（與其他繳費寫入相同）

**入口**

- 繳費紀錄 `/PaymentHistory`：列上「作廢」
- 學生詳情 → 繳費分頁：「作廢」
- 單據／權益更正頁亦可跳去繳費紀錄

### 7.4 作廢後系統會做什麼

| 項目 | 行為 |
| --- | --- |
| 單據列 | 保留；狀態改為「作廢」；單號不變（不可重用） |
| 已繳堂數 | 對應學費入帳會調回（可短暫為負數）；已收款統計不再計入該單 |
| 轉介回贈 | pending 會取消 |
| 月費帳期 | 對應 charge 會作廢／回滾，以便可重開同月 |
| 報讀／點名 | **不會**自動退班；可視為正式報讀但未付款；堂數對帳仍會反映 |
| 電郵 | 僅**原狀態為已收款**時，系統寄通知給 `markyu@mainhope.edu.hk`、`cfan@mainhope.edu.hk`（寄信失敗不影響作廢本身，畫面會提示） |
| 收件匣 | 每次作廢成功後，**系統通知**給行政及外星人；老師看不到。內文含學生、單號、金額、原因與跟進提示 |
| 收據列印／PDF | 顯示「已作廢」標示 |

### 7.5 作廢後前台必須人手跟進

作廢只處理單據與（系統自動處理的）轉介／月費 charge，**不會自動退班**。作廢後請立刻：

1. 該生相關班別是否仍應「就讀中」——不應則另做結束報讀；仍應就讀則另開正確新單收款。  
2. 查看堂數對帳、繳費紀錄是否合理。  
3. 若屬試堂轉正式一併收費：仍視為正式報讀、只不過該筆未付款；僅家長不讀時才另退讀。  
4. 同批手足／同伴是否也要作廢、調整已繳堂數或重開單。  
5. 告知家長：舊收據無效；以新單為準（單號不同）。

收到收件匣「單據已作廢」系統通知時，視同提醒完成上述檢查。管理層會收到已收款作廢電郵，可抽查。

### 7.6 技術備註（部署）

- Edge Function：`void-payment`  
- Secrets：`RESEND_API_KEY`、`RESEND_FROM`（寄件）、可選 `PAYMENT_VOID_NOTIFY_EMAILS`（預設上述兩址）  
- Migration：`payments` 作廢欄位；RLS 撤銷 payments 等表的 DELETE；已繳堂數調動表 `entitlement_pool_adjustments`
