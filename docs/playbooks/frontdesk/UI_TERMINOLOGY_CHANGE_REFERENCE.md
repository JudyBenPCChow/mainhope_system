# 明學教育｜UI 用語更新對照（前台版）

更新日期：2026-08-16  
狀態：畫面已按本表更新（2026-08-16）

本表讓前台人員對照舊稱與統一用語。改名只改稱呼，不改原有營運規則、收費方式或資料。

## 對照表

| 範圍 | 現時畫面可能見到 | 統一用語 | 前台理解 |
| --- | --- | --- | --- |
| 學年 | 正規學年／正規課程 | 常規學年／常規專科班 | 九月至翌年六月；程式資料不變 |
| 常規報讀 | 報足全期／全期報讀 | 報讀 | 常規報讀默認讀至學年結束；不是一次繳全年學費 |
| 暑期報讀 | 第一期／第二期／兩期全報 | 維持不變 | 只屬暑期；說明時要加「暑期」 |
| 指定堂次 | 單堂／單堂報讀 | 單堂 | 只報指定堂次；與試堂不同 |
| 多人同班課程 | 小組課／小組班／小組班別 | 專科班 | 以科目為主、多人同班、通常固定逢星期上課 |
| 私人課程 | 一對一（用作整類總稱） | 私人課程 | 私人課程再分一對一、一對二 |
| 功輔 | 功課班 | 功課輔導班／功輔班 | 獨立產品線，不屬專科班 |
| 班別老師 | 主責／主責老師 | 任教老師 | 該班平時由哪位老師負責 |
| 當日老師 | 當日老師／實際上堂老師 | 實際授課老師 | 該一堂真正授課的老師 |
| 長期換老師 | 換主責／主責變更 | 更換任教老師 | 改班別長期任教老師；不是偶發代堂 |
| 偶發換老師 | 代課 | 代堂 | 只改該堂實際授課老師，任教老師不變 |
| 學費堂數 | 已付堂數 | 已繳堂數 | 已收款並入帳的堂數 |
| 點名堂數 | 已上堂數 | 已扣堂數 | 已按點名規則扣除的堂數 |
| 堂數更正 | 權益池／堂數包／權益池調動 | 已繳堂數／已繳堂數調動 | 單據或科班錯誤時調整已繳堂數 |
| 學生身份 | 注冊／非注冊 | 註冊／非註冊 | 是否為本社正式客戶；試堂或查詢通常屬非註冊 |
| 計糧人數 | HC／計薪 HC | 人頭／計薪人頭 | 該節實際計入薪酬的人數 |
| 機構稱呼 | 校方／本校 | 明學教育／本社／補習社 | 按句子用途選用；物理場地稱校舍 |
| 校曆假期 | 全校停課／停課日 | 校舍假期／本社沒有任何課堂 | 「放假」只用於員工放假 |

## 不會因此改變

- 暑期仍可選第一期、第二期或兩期全報。
- 一對一、一對二仍是私人課程的兩種人數安排。
- 單堂、試堂、報讀仍是三個不同概念。
- 代堂仍只改該堂實際授課老師，不改班別任教老師。
- 系統改名期間如仍見舊稱，含義以本表及《明學教育用語表》為準。
