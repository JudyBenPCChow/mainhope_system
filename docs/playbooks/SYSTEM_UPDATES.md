## 2026-08-31

功課輔導頁面更新︰功課輔導月費頁過往以收款日所屬月份判斷是否已繳，學生詳情亦把功輔顯示為已繳堂數並出現與排程不一致警告。現時已繳改按單據覆蓋的月份核對，學生詳情的功輔報讀改為按月說明，不再以堂數對帳。請到功課輔導的月費頁核對已繳，或於學生詳情報讀班別查看。

功課輔導班月費出單更新︰過往功輔與專科可開在同一張單，欄位亦與專科相同。現時須另開單據，填寫起始月份與月數，不可與專科或試堂同一張單。請到收款登記選學生，如同時報讀專科與功輔，先揀本單類型再出單。

新增學生學校欄更新︰過往新增學生時學校須自行輸入或從較短名單揀選，打錯字便找不到。現時可在學校欄直接打字搜尋全港全日中學，近形錯字仍可命中，名單以外的校名亦可自行輸入。請到學生管理按新增學生，或於前台入學表格填寫學校欄。

學生管理活躍名單更新︰過往活躍名單主要列出當時在讀的學生。現時活躍生包含在讀，以及近三個月曾報讀或退讀者，暑期未續或剛退讀未滿三個月仍會出現在預設活躍頁。請到學生管理以「活躍」與「學生名冊」切換；活躍頁搜尋沒有結果時可轉往名冊。

系統登入網址更新︰部分同事過往開啟系統時會無法連線或顯示找不到網站。現時已增設明學網域登入連結，功能與原網址相同。若曾無法開啟，請改用 https://system.mainhope.edu.hk/ 登入並更新書籤；原網址仍可使用。

功課輔導當值編更更新︰過往老師可報部分時段，編更卻把該人排成全日。現時加入已報更同事時，上班時間跟其所報時段，行政仍可改，同一日可排多於一位，亦不必全日每個時段都有人。月曆會列出當日所有當值同事及上班時間。請到功課輔導的當值編更查看或改派，改後按儲存。

暑期點名查閱更新︰26SM 暑期點名一直按當時報讀的第一期、第二期或兩期全報上紙。現已定明此做法維持不變，不改用本學年已繳堂數，已安排補回的課堂備註亦會保留。請於排程或點名紙改選 26SM 學年查看；本常規學年點名紙不受影響。
