# 系統更新日志

給**行政／財務／管理層同事**閱讀。由新到舊。政策真相見 [`../policies/_INDEX.md`](../policies/_INDEX.md)；操作見各 playbook。

每次說「產出更新總結」會加一則（連日期）。唔當工程 backlog。

**項目編碼：** `SU-YYYYMMDD-NN`。日期即該則當日；`NN` 為當日序號（01 起）。新則接在當日最後一則之下並續號；換日則新開日期節、由 01 起。編碼一經寫入不改號。每則先寫編碼一行，下一行才是更新總結。

## 2026-10-23

SU-20261023-01

SU-20261023-04

## 2026-10-20

SU-20261020-01

SU-20261020-02

SU-20261020-03
新增試堂選班更新︰過往新增試堂的班別只顯示課程名稱與編號，同名班容易選錯。現時下拉附上逢星期與時段，選班後列出任教老師、時間與目前就讀中學生。名單只含目前學年，不含私人課程與已結束班別。請到試堂紀錄按新增試堂，選班後核對。

SU-20261020-04
學生搜尋可按年級更新︰過往請假、試堂、私人課程與學生親友的學生欄主要靠姓名。現時可輸入「中一」或 S1 找出該年級，並記住最近選過的學生。請在上述頁面的學生欄輸入年級或姓名選取。

SU-20261020-05
新增學生後直接報讀更新︰過往在學生管理新增學生成功後，要再搜尋該生才可加入班別。現時一般新生會直接進入詳細頁「報讀班別」，並提示請在此新增報讀班別；已畢業紀錄只建立基本資料。請到學生管理按新增學生，完成後選擇班別加入。
