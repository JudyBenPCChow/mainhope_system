# 系統更新日志

給**行政／財務／管理層同事**閱讀。由新到舊。政策真相見 [`../policies/_INDEX.md`](../policies/_INDEX.md)；操作見各 playbook。

每次說「產出更新總結」會加一則（連日期）。唔當工程 backlog。

**項目編碼：** `SU-YYYYMMDD-NN`。日期即該則當日；`NN` 為當日序號（01 起）。新則接在當日最後一則之下並續號；換日則新開日期節、由 01 起。編碼一經寫入不改號。每則先寫編碼一行，下一行才是更新總結。
