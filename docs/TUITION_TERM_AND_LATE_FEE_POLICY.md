# 學費學期節奏與逾期罰款

介面用語：**繁體中文**。  
性質：**營運政策**（部分條款尚未由系統強制）。索引見 [`OPS_POLICIES.md`](OPS_POLICIES.md)。  
學年／報讀資料見 [`ACADEMIC_YEARS.md`](ACADEMIC_YEARS.md)。

**系統現況（2026-07）：** 逾期罰款項目、自動計算、禁止入室警示與行政通告**尚未在系統實作**；現由前台人手把關（無門禁）。下文政策仍為院方規條，實作時以本檔為準。

## 1. 正規 vs 暑期：收費節奏

| | 正規學年（約九至六月，`YYZZ`／`regular`） | 暑期（`*SM`／`summer_two_period`） |
| --- | --- | --- |
| 報讀 | 常為報足全期（或單堂） | 第一期／第二期／兩期全報／單堂 |
| 學費實務 | **按月**繳交；常見一次約 **4 堂**＝一個月 | 開課前按所報範圍**一次收齊**（例如兩期全報約十二堂量級，或單堂按所報堂數） |
| 遲交場景 | 下月學費理論上月初（如第一個禮拜）應交，但學生／家長可不即交 | 理論上較少「學期中未交學費」 |
| 本檔逾期罰款 | **適用** | **不適用** |

### 例子（正規）

學生報讀九月中文班（正規學年），先交九月約四堂學費。  
十月理論上第一個禮拜應交十月學費；若仍未交，則按第 2 節「月份內第 N 堂」處理。

### 與系統收款工具的對應（現況）

- **堂數包**：`/Payments` 等；UI 預設一次收 4 堂——對齊正規「一個月」慣例。
- **每月學費**（`/MonthlyTuition`）：**已下線**（側欄移除；舊網址轉回收款登記）。相關資料表仍保留供請假結餘等使用；正規學期收款以堂數池＋`/Payments` 為準。
- **追學費（堂數缺口）**：RPC／阿Po 仍可查「已上 ≥ 已繳」；**學生管理列表已取消**此 Tag（2026-07）。此指標**唔等於**本檔「該月學費逾期」罰款規則。

## 2. 逾期罰款與禁止入室（僅正規／九至六場景）

適用：正規學年班、按月繳費情境（暑期班整條不適用；單堂若已按所選堂數一次收齊，預設亦不套用）。

| 條件 | 營運處理 |
| --- | --- |
| 該曆月**第 2 堂**仍未交該月學費 | 收取 **HK$50** 罰款 |
| 該曆月**第 3 堂起**仍未交該月學費 | **不得進入課室** |
| 執行方式 | **前台人員把關**；院內**沒有門禁系統** |

「月份內第 N 堂」：指該生該班在該曆月內、按其可上排程排序後的第 N 堂（細節待系統化時與營運確認：排程列 vs 出席、連堂是否算兩堂等）。

## 3. 行政通告（政策期望）

應能就催繳、罰款、禁止入室發出相關行政通告。  

**系統現況：** 無自動化家長通告；實務靠人手 WhatsApp／話術。職員收件匣亦不以繳費事件為老師主通道。系統化時建議：職員警示 + 預填家長 WhatsApp（與現有提醒模式一致），詳見功能方案（暫未實作）。

## 4. 與「追學費／堂數對帳」的分別

| 概念 | 含義 | 文件 |
| --- | --- | --- |
| 追學費（堂數缺口） | lifetime／班別：**已上 ≥ 已繳**；列表 Tag 已下線 | 阿Po／RPC；非學生列表 |
| 堂數對帳 | 已繳 vs 已綁排程／待補等 | `/LessonBalanceMismatch`、阿Po |
| 本檔逾期罰款 | 正規學期**某曆月學費未續交**，按月內第 2／3 堂 | 本檔 |

前台用語勿混為同一標籤，避免家長／同事誤解。

## 5. 待系統化項目（摘要）

- 罰款項目與出單／豁免  
- 自動判定「該月未交」＋月內第 N 堂（僅正規學年）  
- 前台／點名「禁止入室」警示（不鎖死點名存檔）  
- 行政通告（職員 + WhatsApp 預填）  
- 與雙軌收款（堂數包 vs 月費）對齊  

實作前仍需確認：未繳判定以堂數包定月費為主、第 N 堂計數細則、學費繳清後 $50 是否豁免。
