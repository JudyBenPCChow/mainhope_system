## 1. 適用範圍與名詞

### 1.1 本指南涵蓋甚麼

本指南涵蓋專科班授課薪酬、固定月薪、獨立定價、在家工作時薪，以及指定同事的強積金計算。

### 1.2 常用名詞

| 名詞 | 意思 |
| --- | --- |
| 節 | 一節課堂，標準長度為 75 分鐘 |
| 人頭／HC | 該節實際被扣堂的學生人數 |
| 扣堂 | 該生已消耗該堂學費權益（見第 2 章） |
| 專科班 | 中文、英文、數學等學科班 |
| 一對一／單對單 | 一位教師對一位學生；兩者計法相同 |
| 一對二 | 一位教師對兩位學生 |
| 代堂 | 由非主責教師代替該節授課 |
| 原價 | 未扣優惠／特別折扣前的學費 |
| 總薪酬 | 扣除強積金前的應發金額 |
| 實收 | 扣除僱員強積金供款後，該同事實際應收金額 |

## 2. 通用計糧規則

以下規則適用於所有按課堂計算的薪酬。審核糧單時，應先核對本章，再套用個別同事的計法。

### 2.1 以實際上堂為準，不以收款日期為準

教師薪酬按**該節課堂實際發生並完成點名的月份**計算。

- 學生於七月預繳八月學費：相關教師薪酬計入**八月**。
- 學生已上堂但尚未付款：只要該堂已按規則扣堂，教師**仍應取得**該節薪酬。

### 2.2 甚麼情況計入「人頭」

下列點名狀態視為已扣堂，計入該節人頭或分成基數：

- 現場
- 錄影回放
- Zoom 實時網課
- no show（突然缺席且沒有請假）
- 請假而不需補回

下列狀態**不扣堂**，不計入該節人頭：

- 事假
- 病假

補充說明：

1. 錄影或網課亦屬已上堂，必須計入。
2. 學生正式請假並另行調堂：原課堂不計該生；待補堂完成並扣堂時，才計入補堂當日。
3. 學生臨時請假而校方決定扣堂：計入該節人頭。
4. 若某節最終無人被扣堂，該節**不計薪**。

### 2.3 誰取得該節授課薪酬

**由誰實際上堂，該節授課薪酬即歸誰。**

- 代堂時，薪酬歸代堂教師，按其本人計法計算。
- 班別主責教師若未親自上該節，不得取得該節的「個人授課收益」。

### 2.4 級別如何判斷

初中或高中費率，按**班別／課程所屬年級**判斷，不按學生本人年級。

| 情況 | 採用費率 |
| --- | --- |
| 中四學生上中三班 | 初中 |
| 中三學生上中四班 | 高中 |

專科班應避免初中與高中混合。一個班別只應有一組收費。

### 2.5 一對一、一對二、單對單

- 「單對單」與「一對一」同義，計法相同。
- 一對二若其中一人退讀：應取消原一對二班，另開一對一班，其後按一對一計薪。

### 2.6 惡劣天氣

| 情況 | 是否計薪 |
| --- | --- |
| 課堂已在進行，或師生已到齊並照常上課 | 是，與正常課堂相同 |
| 校方提早通知停課，師生並未到達 | 否 |

### 2.7 學費折扣如何影響分成

凡按學費百分比計算的項目（例如 Mark Yu、Christine Fan、Cyndi Ng 的專科班分成）：

- **一律按原價計算**
- **不理優惠或特別折扣**
- 一張收據含多個班別時，亦按各班原價計算，不因整單折扣而調低

例：原價每堂 $600，折後實收 $500 → 分成基數仍用 **$600**。

### 2.8 不納入分成基數的收費

下列項目不納入百分比分成：

- 教材費
- 試堂費
- 行政費
- 逾期費
- 其他非正式專科班學費

## 4. Mark Yu：分成制

### 4.1 計法

Mark Yu 的薪酬分為兩部分，**不可重複計算同一堂課**：

1. **個人授課收益**：Mark Yu 親自上堂，並已扣堂的專科班學費原價 × 60%
2. **他人授課佣金**：其他教師教授下列科目，並已扣堂的學費原價 × 10%
   - 數學（必修部份）
   - 數學延伸部分（單元一 M1）
   - 數學延伸部分（單元二 M2）
   - 以上包括所有年級

```text
Mark Yu 總薪酬
= 個人授課收益
＋ 他人數學／M1／M2 佣金
```

### 4.2 重要原則

1. Mark Yu 親自教授的課堂，只取 60%，**不再另加 10%**。
2. Mark Yu 當月即使完全沒有親自授課，只要其他教師有教授上述科目，仍可取得 10% 佣金。
3. Mark Yu 的班由其他人代堂時：
   - 代堂教師按自己的計法取得該節薪酬；
   - Mark Yu **沒有**該節 60%；
   - Mark Yu **有**該節 10% 佣金（若屬數學／M1／M2）。

### 4.3 例子

假設某月：

| 項目 | 金額 |
| --- | --- |
| Mark Yu 親自教授並已扣堂的專科班學費原價 | $3,000 |
| 其他教師教授數學／M1／M2 並已扣堂的學費原價 | $10,000 |

計算：

```text
個人授課收益 = $3,000 × 60% = $1,800
他人授課佣金 = $10,000 × 10% = $1,000
總薪酬 = $2,800
```

再假設 Natalie Kwok 代 Mark Yu 上一節數學課，該節已扣堂學費原價 $800：

```text
Natalie Kwok：按兼職專科班人頭計法取得該節薪酬
Mark Yu：該節無 60%；另得佣金 $800 × 10% = $80
```

## 5. Christine Fan：分成制

### 5.1 計法

Christine Fan 的薪酬同樣分為兩部分：

1. **個人授課收益**：Christine Fan 親自上堂，並已扣堂的專科班學費原價 × 60%
2. **他人授課佣金**：其他教師教授**中國語文**，並已扣堂的學費原價 × 10%
   - 包括所有年級
   - 不包括中國歷史、中國文學及其他獨立科目

```text
Christine Fan 總薪酬
= 個人授課收益
＋ 他人中國語文佣金
```

### 5.2 重要原則

1. Christine Fan 親自教授的課堂，只取 60%，不再另加 10%。
2. Christine Fan 的班由其他人代堂時：代堂教師按自身計法計薪；Christine Fan 該節無 60%，但若屬中國語文，仍有 10% 佣金。
3. 功課班佣金現階段不納入本指南的每月計算，見第 16 章。

### 5.3 例子

假設某月：

| 項目 | 金額 |
| --- | --- |
| Christine Fan 親自教授並已扣堂的專科班學費原價 | $4,000 |
| 其他教師教授中國語文並已扣堂的學費原價 | $7,600 |

計算：

```text
個人授課收益 = $4,000 × 60% = $2,400
他人授課佣金 = $7,600 × 10% = $760
總薪酬 = $3,160
```

再假設 Billy Shek 代 Christine Fan 上一節中國語文課，該節已扣堂學費原價 $1,000：

```text
Billy Shek：按兼職專科班人頭計法取得該節薪酬
Christine Fan：該節無 60%；另得佣金 $1,000 × 10% = $100
```

## 7. 兼職專科班導師：按人頭計薪

### 7.1 適用同事

Cheryl Ng、Billy Shek、Liam Lai、Leo Chan、Natalie Kwok、Kenneth Li、Emma Cai、Phoebe Tam

（Judy Chu 見第 8 章；其費率不同。）

### 7.2 小組班公式

先計算該節**實際扣堂人頭**：

```text
實際扣堂人頭 = 該節所有已扣堂的學生人數
```

初中（中一至中三）：

```text
每節薪酬 = $120 ＋ $60 ×（實際扣堂人頭 − 1）
```

高中（中四至中六）：

```text
每節薪酬 = $150 ＋ $70 ×（實際扣堂人頭 − 1）
```

月薪為當月各節薪酬相加。

### 7.3 一對一／一對二

| 班型 | 計法 |
| --- | --- |
| 一對一／單對單 | 按等效 3 人頭計算 |
| 一對二 | 按等效 4 人頭計算 |

初中一對一：

```text
$120 ＋ $60 × 2 = $240／節
```

高中一對一：

```text
$150 ＋ $70 × 2 = $290／節
```

初中一對二：

```text
$120 ＋ $60 × 3 = $300／節
```

高中一對二：

```text
$150 ＋ $70 × 3 = $360／節
```

### 7.4 例子

四人高中班，當日一人現場、一人錄影、一人病假、一人事假：

```text
實際扣堂人頭 = 2
每節薪酬 = $150 ＋ $70 ×（2 − 1）= $220
```

Liam Lai 代 Kenneth Li 上一節初中三人小組班，三人皆扣堂：

```text
實際扣堂人頭 = 3
Liam Lai 該節 = $120 ＋ $60 × 2 = $240
Kenneth Li 該節 = $0（未上堂）
```

## 13. 強積金

### 13.1 誰要計算

目前只計算下列四人：

- Mark Yu
- Christine Fan
- Sophie Yu（行政人員）
- Katie Lee

其餘同事一律不在本指南的強積金計算範圍內。

### 13.2 如何計算

先計算該人當月**總薪酬**（未扣強積金前），再按下表：

| 每月總薪酬 | 僱員供款 | 僱主供款 |
| --- | --- | --- |
| 低於 $7,100 | $0 | 總薪酬 × 5% |
| $7,100 至 $30,000 | 總薪酬 × 5% | 總薪酬 × 5% |
| 高於 $30,000 | $1,500 | $1,500 |

糧單應分開列示：

```text
總薪酬
− 僱員強積金供款
= 實收金額

另列：僱主強積金供款（公司成本，不從實收再扣）
```

### 13.3 例子

| 同事／情況 | 總薪酬 | 僱員供款 | 僱主供款 | 實收 |
| --- | --- | --- | --- | --- |
| 假設總薪酬較低 | $5,000 | $0 | $250 | $5,000 |
| Sophie Yu（行政人員） | $16,000 | $800 | $800 | $15,200 |
| Katie Lee | $20,000 | $1,000 | $1,000 | $19,000 |
| 假設總薪酬較高 | $45,000 | $1,500 | $1,500 | $43,500 |

## 14. 每月出糧流程

建議按下列步驟處理：

### 第一步：確認月份資料齊備

核對該月：

1. 各班點名是否完成；
2. 代堂紀錄是否正確；
3. Cody Cheong 的在家工作時數是否已申報並獲核准；
4. 各同事是否已有適用費率或月薪。

### 第二步：按同事計法計算

依照第 4 至 12 章，逐人計算總薪酬。

### 第三步：計算強積金

只對 Mark Yu、Christine Fan、Sophie Yu、Katie Lee 套用第 13 章。

### 第四步：審核異常

重點檢查：

1. 有課堂但未點名；
2. 教師未設定費率；
3. 金額較上月明顯偏高或偏低；
4. 代堂歸屬是否正確；
5. 分成是否誤把折扣後金額當作基數。

### 第五步：確認結算

確認後，該月糧單應作為該月正式紀錄保存，供日後查閱及統計公司支出。

## 15. 異常與人手調整

### 15.1 甚麼屬於異常

下列情況不應依賴自動規則擅自改數，應列入異常，由財務及管理層獨立處理：

1. 學生已扣堂、教師已計薪後才退學費；
2. 退款影響 Mark Yu／Christine Fan 已計算的佣金；
3. 已結算後才發現漏點名、錯費率或錯代堂；
4. 已結算後要求取消代堂紀錄；
5. 其他本指南未涵蓋的特殊協議。

### 15.2 已結算月份發現錯誤

原則：應**調整原先那個月份的糧單**，使該月收入與支出統計正確。

例：九月發現 Natalie Kwok 八月漏算兩節 → 調整**八月**糧單，而不是只在九月隨意加一筆而讓八月永遠不正確。

### 15.3 人手調整程序

```text
由財務提出調整並寫明原因
→ 經管理層核准
→ 才可改動糧單
```

調整紀錄應保留：

- 原金額
- 調整後金額
- 原因
- 經手人
- 核准人
- 日期時間
