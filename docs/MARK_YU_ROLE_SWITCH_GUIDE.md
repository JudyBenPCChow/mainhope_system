# Mark Yu 雙身份使用指引

Mark Yu 的帳戶同時具有以下兩個操作身份：

- **專科班老師**：處理自己的班別、課堂、點名及老師日常工作。
- **管理員**：處理全校學生、班別、排程、收費及行政工作。

系統會按目前選擇的身份顯示功能及限制資料權限。請按照當刻工作的性質選擇身份。

## 如何切換身份

### 電腦版

1. 使用 `markyu@mainhope.edu.hk` 登入。
2. 在左側選單底部找到「目前操作身份」。
3. 選擇「專科班老師」或「管理員」。
4. 系統會返回首頁，並以新身份重新載入選單及資料。

若左側選單已收起，請先按選單上方的展開箭咀。

### 手機版

1. 登入後打開左上角的主選單。
2. 在選單底部找到「目前操作身份」。
3. 選擇需要的身份。
4. 系統會返回首頁，並套用新身份。

> 切換身份會離開目前頁面。若正在填寫表格，請先儲存資料再切換。

## 何時使用「專科班老師」

進行自己的教學工作時，請使用專科班老師身份。

主要功能包括：

- 查看「我的班別」及自己負責的學生。
- 查看自己的時間表及排程。
- 進行點名及更新出席紀錄。
- 查看及填寫教學紀錄。
- 查看自己的一對一學生。
- 預約空房。
- 查看及更新個人資料。
- 收件匣通知（排程／請假／點名提醒等）。

老師身份的資料範圍：

- 只會看到自己負責的班別、課堂及相關學生。
- 可更新獲准的課堂狀態及點名資料。
- 不可新增或刪除排程。
- 不可修改班別設定或自行為班別加入學生。
- 不可查看收費、全校學生名單及其他行政資料。

## 何時使用「管理員」

處理全校行政或跨老師工作時，請切換至管理員身份。

主要功能包括：

- 前台指引精靈、明日課堂提醒及話術庫。
- 全校學生管理及家長報讀申請。
- 增退紀錄、試堂紀錄及一對一學生管理。
- 人數報表、中學出席統計、堂數對帳及宣傳配對。
- 班別新增與管理。
- 老師管理、老師檔期規劃及課室管理。
- 全校排程、教學紀錄及出席紀錄。
- 老師請假、學生請假及約房審批。
- 收款登記及繳費紀錄。

管理員身份不包括最高系統權限，因此不能使用：

- 用戶帳戶管理。
- 系統日志及報錯管理。
- 課程底層設定。
- 推薦回贈管理。
- 外星人專用的智能分析功能。

以上功能只限「外星人」身份，Mark Yu 的帳戶不具備該身份。

## 建議使用方式

- 上課、點名、查看自己的學生：使用「專科班老師」。
- 安排全校班別、處理報讀、收費或行政：使用「管理員」。
- 完成行政工作後，可切回老師身份，避免誤看或誤改不相關資料。
- 操作紀錄會按照當時使用的身份記錄，因此開始工作前應先確認身份。

## 常見問題

### 看不到身份選擇器

1. 確認登入電郵為 `markyu@mainhope.edu.hk`。
2. 重新整理頁面。
3. 登出後重新登入。
4. 若仍未出現，請聯絡系統管理員確認雙身份設定是否已部署。

### 切換後找不到原本的功能

不同身份會顯示不同選單。請查看「目前操作身份」，並切換至適合該工作的身份。

### 顯示「沒有獲授予所選身份」

系統拒絕了未授權的角色切換。請重新整理或重新登入；若問題持續，請聯絡系統管理員。

### 切換身份後未儲存的內容消失

切換時系統會返回首頁，未儲存的表格內容不會保留。下次請先完成儲存再切換。
