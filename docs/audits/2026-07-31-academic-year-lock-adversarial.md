## 1. 總評（對抗性）

顧問拍板後的路線（A1 修判斷＋UX；A2 政策彈性；T-B；點名歷史可睇不可改）**方向正確**，且「危險 `endDate` 僅檔期三處」令 A1 blast radius 細。

但用「惡意誤用／時序錯位／字面執行顧問回覆」壓測後，發現若干**高嚴重度矛盾**：若照字面做，會出現「修完 L1 反而更痛」或「遷移寬限寫咗文件卻救唔到 `2526`」。這些不是否定 A1，而是**A2 條款與上線節奏必須先寫死**，否則不應宣稱 L13 已解決。

## 2. 高風險發現

### ADV-1 — A1 與 A2 空窗：營運可能倒退

**攻擊／場景**：只合併 A1（admin 永遠用真實今天），A2（30 日窗＋遷移）尚未上線。

**現況**：檔期 L1 bug 令 admin 選 `2526` 時**錯誤可編**（誤打誤撞可改歷史檔期）。

**A1 之後**：鎖變「正確」→ admin **正式不能**改 `2526`；遷移／30 日窗尚未存在。

**結果**：行政清理 `2526` 殘務（點名錯帳、請假、檔期）短期比而家更難，只剩外星人。L13 痛點在 A1→A2 之間可能**加劇**。

**請顧問確認**：

- (a) 接受並在上線公告寫明「A1 後短暫更緊，A2 先至有寬限」；還是  
- (b) 要求 A1／A2 **同發或緊接**；還是  
- (c) A1 例外保留某種臨時開關（我們較不建議）？

---

### ADV-2 — 「遷移寬限不寫入程式」與「要救現債」矛盾

顧問 Q1：

- **永久規則**：結束後 30 日內可編。  
- **一次性遷移**：`2526`／`25SM` 寬限至 **2026-08-31**，並寫「不寫入程式／只寫文件或公告」。  
- A2 才實作過渡窗。

**字面推演（今日 ≈ 2026-07-31）**：

- `2526` 的 `end_date` = 2026-06-30 → `今天 − end` = **31 日** > 30 → **永久 30 日窗救唔到 `2526`**。  
- 若 A2 程式**只有**永久 30 日、無截止日期例外 → Q1「給行政整個八月清 `2526`」**落空**。

**結論**：遷移條款若要有營運效果，**必須入 A2 程式**（常數、`academic_years` 旗標、或 env／截止日），不能只靠 `ACADEMIC_YEARS.md`。

**請顧問確認**：是否修正為「遷移寬限**寫入 A2 程式**，文件只係對外說明」？若堅持不寫程式，Q1 應改回 (a) 現債继续 alien，避免假承諾。

---

### ADV-3 — `25SM` 寬限至 2026-08-31 過闊

`25SM` 結束於 **2025-08-31**。寬限至 2026-08-31 ≈ 結束後再開放近 **12 個月**。

**風險**：遠舊於 `2526` 的暑期資料長時間可被 admin（若再套 T-B，甚至 teacher）改寫；攻擊面／誤操作面遠大於「剛結束正規年」。

**請顧問確認**：遷移是否改為：

- **只** `2526` → 2026-08-31；或  
- `25SM` 用更短窗／不納入遷移；或  
- 維持現寫法並接受一年風險（請明示）？

---

### ADV-4 — T-B ∩ 過渡窗／遷移 → 老師一齊解開歷史

顧問 Q4：Teacher =（≥ 地板）∩（Admin 可編集合，含目前＋下一＋**過渡窗**）。

**場景**：為讓行政對帳而開 `2526` 遷移／30 日窗 → 同一集合對 teacher 亦開。

**風險**：專班老師可改歷史點名／請假（視 UI 是否暴露），與「過渡窗係行政對帳工具」敘事不符；亦放大誤改。

**請顧問確認**：過渡窗與一次性遷移是否改為 **admin（＋alien）only**，teacher 維持「地板 ∩（目前＋下一）」**不含** grace？我們傾向 admin-only grace。

---

### ADV-5 — 顧問草稿對「空 label」語意不一致

Q7 建議：

```ts
isAcademicYearEditableForAdmin: !label → return false   // 不可編
isAcademicYearReadOnly (admin): !label → return false   // 非唯讀＝可編
isAdminEditableAcademicYearLabel: !label → return true  // 可編
```

三處對「空 label」不一致。A1 若並列實作，路徑不同會導致可編／不可編跳動。

**請顧問確認 A1 唯一語意**（我們建議與現況／L4 一致）：

> 空 label → **可編**（避免舊資料鎖死）＋ `console.warn`／可選 audit；  
> 唔好在 `EditableForAdmin` 單獨改成 false。

## 3. 中風險發現

### ADV-6 — L3 日期路徑在 A1 後仍是 magick 解鎖

A1 不改 `canEditAcademicYearForDate`。  
例：`2526` 班於 **2026-07** 開補堂 → 日期推 `26SM` → **可編**；班別實體仍屬 `2526`。

修 L1 後，行政仍可經「暑期日＋舊班補堂」改到營運上屬舊年的排程／點名（寫入 guard 仍認日期）。

**請顧問確認**：A1 接受為已知債並寫入 backlog 風險？定要在 A1 對「班別詳情內操作」先行用 class label（範圍膨脹）？

---

### ADV-7 — 繳費「任一班可編＝整單可編」可被利用

顧問 A2：多班且跨學年時，任一班可編 → 整單可編。

**對抗**：舊學年明細 + 加一條當期班／當期雜費行 → 可能解鎖改舊年金額。

**請顧問確認 A2 偏好**：

- (a) 維持「任一可編」（務實，接受風險＋audit）；  
- (b) 「全部關聯班都可編先至整單可編」；  
- (c) 按 `payment_details` 分行上鎖？

---

### ADV-8 — 可編集合 vs 學年下拉不同步

`filterAcademicYearOptionsForEdit` 而家 admin 只給「目前＋下一」。A2 若可編含過渡／遷移學年，但下拉仍無該 label → 可寫資料卻揀唔到學年／檔期要靠深鏈。

**請顧問確認**：A2 凡改 `isAdminEditable*`，**必須同步** `getAdminEditableAcademicYearLabels`／`filterAcademicYearOptionsForEdit`（含 grace／遷移 label）。

---

### ADV-9 — A1 UX 降級漏網即失敗

黃橫幅／`academicYearEditBlockedMessage` 散落點名、班別、排程、請假、繳費、檔期等。漏一頁＝「系統壞咗」敘事仲在。

**請顧問確認**：A1 驗收是否要求「枚舉並改完所有警報式學年鎖橫幅呼叫點」作為 done 定義（我們建議是）？

---

### ADV-10 — `todayYmd` 時區

若 service／edge 用 UTC「今天」，HK 日界附近會跳「目前學年」與 30 日窗。

**請顧問確認**：一律與 `academicYearLabelFromStartDate(null)` 相同——**瀏覽器／營運本地日曆日**（Asia/Hong_Kong 或已約定本地），禁止伺服器 UTC date 作 asOf。
