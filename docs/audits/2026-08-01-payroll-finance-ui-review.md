## 0. 財務職責（審查基準）

依指南 §14–15 及已定角色分流，財務應能在系統內完成：

1. **資料齊備**：點名、代堂、Cody 工時、費率／月薪是否齊  
2. **核對計算**：各模式（分成／HC／月薪／獨立定價／WFH）數字是否合理  
3. **處理異常**：硬阻擋先清；軟提醒有註記  
4. **人手調整**：提出＋寫原因，交管理層核准  
5. **提交核實**：交管理層；自己不能結算  
6. **匯出／留底**：預覽或結算後檔案可供對帳  

以下逐點只寫**仍欠／不便**之處（已做得好的見文末 §已具備）。

---

## 1. 高優先（直接阻礙或易出錯）

### 1.1 缺「月結齊備」檢查清單

- **問題**：指南第一步要求核對點名／代堂／Cody／費率，現頁只有零散異常字句，沒有可勾選的齊備清單與完成度。  
- **影響**：財務不知「還差幾項才能安心提交」。  
- **建議**：頂部加「本月齊備度」：未點名堂數、缺費率人數、Cody 工時狀態、代堂待核對數；每項可點進清單。

### 1.2 Cody 工時無法在頁內輸入／核准狀態不清

- **問題**：指南與 UI 設計均要求財務（或流程）補 WFH 時數；現只有異常字＋金額「—」，無時數欄、無「已申報待核准／已核准」狀態。  
- **影響**：無法完成 Cody 一條龍審核，只能口頭／另表處理。  
- **建議**：Cody 明細內嵌工時表單（時數＋備註）；狀態機：未報／已報待核准／已核准；未核准不可計入總額（可提交其他人）。

### 1.3 硬阻擋可用一勾「已知悉」繞過

- **問題**：未點名／缺工時可靠 checkbox 提交；正式流程應阻擋或「該人暫緩、其餘提交」。  
- **影響**：易在資料未齊時交管理層，增加退回。  
- **建議**：硬阻擋預設禁止提交；允許「排除該同事後提交其餘」；已知悉繞過僅限 alien 後門或需雙重確認＋原因。

### 1.4 無「逐人已審」進度

- **問題**：12 人明細很長，沒有「此人已核對」標記／進度（例如 7/12）。  
- **影響**：審到一半易漏人，尤其分成制與多班教師。  
- **建議**：每列加「已審」勾選（本機或存草稿）；提交前顯示未審名單。

### 1.5 分成制（Mark／Christine）難核對「是否用原價」

- **問題**：指南強調佣金／60% 以**原價**為基；現只見金額與簡短 note，看不到「原價基數合計、折扣差額、10% 池來自哪些教師／哪些節」。  
- **影響**：財務無法在介面驗證最易錯的分成規則。  
- **建議**：分成明細獨立區塊：個人原價合計→×60%；他人指定科目原價合計→×10%；可展開池內貢獻清單（教師、班、節、原價）。

### 1.6 代堂歸屬未成一等公民檢視

- **問題**：指南要求核對代堂；現只藏在逐堂 note，總覽無「本月代堂進出」摘要。  
- **影響**：Kenneth／Liam 類個案要靠掃全文。  
- **建議**：每人加「代出／代入」小計；異常列點擊直達該節；可篩「含代堂」。

### 1.7 人手調整未對齊指南 §15.3，且管理層看不見

- **問題**：表單僅有金額＋原因；缺經手人、時間、調整對象月份；送出後只留財務頁本地列表，管理層核實台無待核准調整。  
- **影響**：無法演示／承接「財務提出→管理層核准→入帳」。  
- **建議**：調整單含完整欄位；狀態待核准／已核准／已拒絕；管理層頁顯示待核准佇列；核准後才改總薪酬。

### 1.8 異常無法一鍵跳到「出事那一節」

- **問題**：異常文字可選中同事，但仍要人手翻年級／班／堂。  
- **影響**：堂數多時審核成本高。  
- **建議**：異常附 deep-link（同事＋班＋堂 id）；未點名直接高亮該 LessonCard。

## 2. 中優先（降低效率或增加誤判）

### 2.1 財務總覽缺「較上月 %」

- **問題**：波動異常寫在字裡，總覽表無較上月欄（管理層才有）。  
- **建議**：財務總覽亦顯示較上月％與上月金額，方便掃視。

### 2.2 缺費率／HC＝0 等異常類型未覆蓋

- **問題**：指南 §15.4／UI 設計列有缺費率、HC 為零；原型幾乎只演示未點名、缺工時、金額波動、代堂。  
- **建議**：補齊異常類型與對應處理 CTA（例如「前往費率設定」— 正式版）。

### 2.3 無模式／關鍵字篩選

- **問題**：固定月薪、分成、HC 混在同一長表，不能篩「只看異常」「只看兼職 HC」。  
- **建議**：篩選：異常／模式／有代堂／未審。

### 2.4 計算公式與費率速查不可見

- **問題**：財務核對 HC 時要心算或另開指南 §17。  
- **建議**：展開明細顯示「本節計法」（如 $150+$70×(n−1)＝$x）；側欄或抽屜附費率速查（唯讀）。

### 2.5 CSV 欄位未對齊「銀行用／對帳用」

- **問題**：現 CSV 有薪酬欄，無銀行帳號、實發優先排序、調整註記；與初稿「銀行批量轉賬」目標有落差。  
- **建議**：財務預覽 CSV＝對帳用（含堂數／異常）；管理層正式 CSV＝銀行用（姓名、帳號、實發、備註）；兩者分開說明。

### 2.6 「重新計算」無結果回饋差異

- **問題**：按鈕只提示示範，看不到重算前後差異。  
- **建議**：正式版顯示重算摘要（金額變動人數、新增未點名等）；原型亦可 mock diff。

### 2.7 提交核實缺摘要確認頁

- **問題**：一鍵提交，無「將提交：總薪酬／異常數／排除人員／待核准調整」確認。  
- **建議**：提交前 Confirm Dialog 列重點數字與未清項。

### 2.8 已結算後改數（指南 §15.2）無入口

- **問題**：要求改**原月份**糧單；現已結算月完全唯讀，無「申請更正該月」流程。  
- **建議**：已結算月允許「發起更正案」→ 財務填原因 → 管理層核准 → 產生調整紀錄（非默默改數）。

## 3. 低優先（體驗／完整度）

### 3.1 手機長頁審核吃力

- 財務主戰場偏桌面；手機可做異常佇列＋單人審核，完整堂數表保留桌面。

### 3.2 沙盒「預覽身份」易與真實角色混淆

- 正式上線後應依登入角色進對應頁，勿並排切換；沙盒保留即可但加更醒目標籤。

### 3.3 缺個別糧單 PDF

- UI 設計列為第二期；財務／老師對帳有用，可排期。

### 3.4 無操作審計日誌 UI

- 重算、提交、調整、退回應有時間線，方便事後追查（可先做簡單列表）。

### 3.5 退款／佣金回沖異常未建模

- 指南 §15.1 退款影響分成；現無此異常類型與處理入口。

### 3.6 一對一「等價人頭」說明不足

- HC 制一對一＝3 人頭等規則只在指南；明細應顯示等價人頭，避免財務疑惑「為何 1 人收 3 人頭價」。

## 4. 對照指南步驟：覆蓋度

| 指南步驟 | 現 UI | 評語 |
| --- | --- | --- |
| §14.1 資料齊備 | 部份（異常字） | 欠結構化齊備清單 |
| §14.2 按人計法核對 | 有堂數分層＋金額 | 欠公式／原價池透明 |
| §14.3 MPF | 有總覽與每人腳 | 可接受；可標「適用四人」 |
| §14.4 審核異常 | 有佇列 | 類型不全、跳轉弱、硬阻擋過鬆 |
| §14.5 結算 | 財務改為提交核實 | 符合分流；欠提交摘要 |
| §15.3 人手調整 | 有表單雛形 | 欄位／核准鏈／入帳未完 |
| §15.2 結算後改月 | 無 | 需補 |

## 5. 已具備（暫不列為改善）

- 財務／管理層**兩套版面**分流正確  
- 異常排前、儀表板總額／MPF／實發／堂數  
- 堂數統計對齊中學出席統計層級（類別→年級×類型→班→逐堂）  
- 財務不可結算、管理層可退回／結算  
- Mock CSV 可下載（欄位仍需按上列強化）  
- 沙盒免登入供遠端評 UI

## 6. 建議下一波 UI 實作順序（僅建議）

1. 月結齊備度＋異常 deep-link＋逐人已審  
2. Cody 工時輸入／狀態；硬阻擋改「排除後提交」  
3. 分成原價池明細；代堂進出摘要  
4. 人手調整全鏈（財務→管理層可見核准）  
5. 提交確認摘要；CSV 分對帳／銀行兩種  
6. 結算後更正案；其餘低優先項
