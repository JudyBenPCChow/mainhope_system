## 一句

取代 Notion 的功輔「按日學生日誌」：老師在後台寫當日情況（上線日起新寫），家長在 Portal 只讀自己子女的紀錄；上線即棄用 Notion，系統為唯一真源。

## 開工閘

- 母題功輔產品已關帳；**本題不重開**報讀／月費／編更範圍。
- **欄位與家長可見範圍已拍板**（見「已定」）。Schema／後台 UI 開工中；Portal 前端在 `mainhope_portal`。
- Portal 前端與後台可同波或分 PR，但 **RLS 必須先於 Portal 上線**（家長只能讀自己 `student_id`）。
- 不擋：專科點名、非常規排程、計糧。

### 當日列欄位（`homework_student_day_logs`）

唯一鍵：`(student_id, log_date)`。

| 來源／用途 | 欄位 | 必填 | 家長可見 |
| --- | --- | --- | --- |
| 負責老師 | `teacher_id`（預填當日編更，可改） | 建議必填 | 是（姓名） |
| 到達／離開 | `arrived_at`／`left_at`（按鈕時間戳） | 選填 | 是 |
| 已上足 2 小時 | `full_two_hours` | 建議必填（是／否） | 是 |
| 未足原因 | `hours_note` | 否時建議必填 | 是 |
| 已完成功課 | `homework_done` | 建議必填（是／否） | 是 |
| 當日欠什麼 | `homework_owed` | 否時建議必填 | 是 |
| 有默測 | `has_dictation` | 選填 | 是 |
| 溫習狀態 | `revision_note` | 選填 | 是 |
| 手冊狀態 | `handbook_status`（有圖／無手冊／無功課） | 建議必填 | 是 |
| 家長可見備註 | `parent_note` | 選填 | 是 |
| 僅職員備註 | `staff_only_note` | 選填 | **否** |

### 持續項目（與當日列分開）

建議表名：`homework_student_followups`。

| 欄位概念 | 說明 |
| --- | --- |
| `student_id`、類型（欠功課／默測）、正文 | 家長與職員可見 |
| `ends_on` | 結束日（含當日仍顯示） |
| 建立日／建立者 | 稽核 |
| 已完成標記 | 可提早結束，避免無限掛住 |

今日情況／Portal：列出 `ends_on >= 今日` 且未標完成的項目。

### 常設指示（學生級，非按日）

長文欄（`students` 擴欄或功輔專用列）：`standing_instructions`。Portal 與職員可讀；僅職員可寫。

### 相片／Storage

**現況（2026-09-26 查庫）：** 無日誌表；Storage 僅有 `expense-journal-attachments`（約 15 MB）。**不足以**承載功輔相片，波次 1 必須新建。

| 項目 | 定案 |
| --- | --- |
| Bucket | 新建 private（例如 `homework-day-log-attachments`）；允許 image（必要時 pdf）；單檔上限約 5–10 MB |
| 路徑 | `{academic_year_code}/{student_id}/{log_date}/{kind}_{uuid}.ext` |
| 種類 | handbook／dictation／other（附件子表或多路徑欄） |
| 壓縮 | 上傳前縮邊長／品質（建議最長邊 1600–2048px） |
| 上限 | 每生每日最多 10 張（R6） |
| RLS | 職員寫；Portal 只讀自己學生；**不可**沿用 `expenses.record` |
| 預算 | 不另訂第三方；吃現有 Supabase Storage。組織若仍為 Free（1 GB）上線前應預期升 Pro（100 GB 內）；超額約 US$0.0213／GB／月 |
| 後補另題 | Portal 只熱載近 N 個月；退讀到期自動刪；舊學年冷儲 |

簽章 URL 模式可參考日記帳附件，bucket／政策全新。

## 今日批次填寫（產品）

1. 入口：功輔「功課紀錄」→ **今日**名冊（與全部學生圖庫分 Tab）。
2. **漸進流程（實務）**：學生到達 → 名冊按「到」即建檔；上課期間多次「更新」＋拍照；學生離開 → 按「離」。**不是**一次填完才儲存。
3. 列狀態：未建檔／進行中／已離開；可標「日結未齊」（兩小時／功課／手冊尚未選）。
4. 到達／離開＝即時寫入時間戳（名冊或詳情內皆可）；其餘欄按「更新紀錄」寫入；可先存半成品。
5. 預填負責老師＝當日編更（可改）；寫入即 Portal 可見；`staff_only_note` 不暴露。
6. 缺席／未到：仍可建列（不按到達＋備註）；**不**當點名／扣堂。
7. 首版不做：整班複製昨日、草稿／發佈、WhatsApp 推送。
