# 權益池按人還是按班 — 顧問簡報

| 欄位 | 值 |
| --- | --- |
| 對象 | 了解明學營運、未跟今輪工程嘅顧問 |
| 目的 | 請對「堂數池按學生共用、點名紙仍分班」給予意見 |
| 狀態 | **產品傾向，尚未改系統**。現役仍係一班一個池 |
| 日期 | 2026-08-15 |
| 母題 | [報讀包裝與點名權益](./summer-enrollment-roster-consistency.md) |


## 1. 請你睇完後答

1. 紙分班、池按人，會唔會令前線或家長更難對帳？
2. 同時讀兩科時，學費單仍按班寫堂數、入池卻唔分科 — 可接受嗎？
3. 有冇必須繼續「一科一池」嘅情況（一對一、連堂、不同收費）？
4. 試堂應否繼續完全隔離，唔入正規總池？


## 2. 背景（工程做過咩、點解有「池」）

明學前線直覺係：**收咗幾堂錢，就應該嚟幾堂；改期唔改「有冇份」。**

舊系統收費按堂數，點名紙卻長期用「日曆推算邊個應該嚟」。改期、跨期補堂、加堂之後，紙會缺人，或者有人喺紙上但其實唔知扣邊啲已購堂。

2026 年 8 月起，後台改用三層，避免再用日期估名單：

| 層 | 用白話講 | 而家系統點做 |
| --- | --- | --- |
| 報讀 | 呢個學生讀邊班 | 就讀中／退讀 |
| 到課宣告（點名紙） | 呢一堂預計邊個嚟 | 有報讀＋有排程就上紙。**唔睇有冇餘額**（欠費都可以上紙） |
| 權益池 | 重有幾堂可用 | 確認收款先加堂數；老師點名屬「計費」先減。可負（先上課後補交） |

已拍板、同今次選擇無關、希望顧問當前提：

- 開排程、加堂、報讀 **都唔加** 可用堂數；只有學費單上的堂數入池。
- 常規唔退費；剩堂跟人走，唔退錢。
- 試堂：確認學費單（可 $0）之後先上紙。
- 點名：現場／no show／錄影等扣堂；事假／病假在紙上但不扣堂。
- 正規學年 `2627` 先用新路徑；暑期 `26SM` 暫仍舊路徑。

**現役實作（顧問請當「而家電腦點計」）：** 權益池係 **一個學生 × 一班 × 一個學年** 一個數字。交英文嘅堂，只會被英文點名扣。轉科要由人把剩餘從 A 班池搬去 B 班池。

呢套尚未用真實 `2627` 班做過現場全鏈驗證（時間表仍未入 production）。


## 3. 點解要重新揀「池點分」

轉科少見，唔值得為佢開前台專頁。真正日常係下面呢種 **總數不變、科目對調**：

> 學生報中文同數學，一個月大約交 8 堂。  
> 中文請咗 1 堂假（唔嚟、唔補、唔扣），數學加咗 1 堂。  
> 總消耗仍係 8 堂。前台貪方便，請假同加堂都唔入系統 — 因為「總數都係 8」。

若堅持嚴格一科一池、又要求人手把 1 堂從中文搬去數學：前線唔會做。帳面會變成中文剩 1、數學欠 1，收銀仲可能催數學補交。家長則認為已經交夠 8 堂。

若完全唔入系統：老師中文紙仍當佢會嚟，數學加堂紙冇名。呢個正正係舊年點名缺人嘅根因。

所以要分開兩件事：

- **可以同 8＝8 對齊嘅：** 扣堂時唔分科（一個學生一個剩餘）。
- **唔可以貪方便省掉嘅：** 請假、加堂一定要入點名紙。


## 4. 考慮因素

| 因素 | 說明 |
| --- | --- |
| 同一級小組課價錢相同 | 扣中文定數學，對錢嚟講等價；「互食」唔等於多送或少收。 |
| 同時讀兩科好常見 | 比轉科常見得多。池若按人，剩餘係「呢個人重有幾堂」，唔係「英文剩幾堂、數學剩幾堂」。 |
| 收據仍按班開 | 單上可以寫中文 4＋數學 4，方便對帳；入池若唔分科，單上班別只記「錢記喺邊行」，唔再等於「呢 4 堂只能上中文」。 |
| 點名紙必須分班 | 老師要知呢堂邊個嚟。池有剩 **唔等於** 自動出現喺未報讀、未加堂嘅紙。 |
| 前線會繞過麻煩步驟 | 要佢哋為 8＝8 再搬 1 堂，實務上等於冇呢步。 |
| 試堂／一對一／連堂 | 試堂已規定出單先上紙，宜唔好混入正規袋。一對一若收費唔同，可能仍要獨立。連堂一格扣 2 堂，按「單位」扣總池即可。 |
| 學年 | `26SM` 同 `2627` 唔好共用一個剩餘。 |
| 權限 | 直接改池只限外星人；行政／管理層將來走申請。今次只改「池點分」，唔改邊個可以改數字。 |


## 5. 方案對照

### A — 現役：一班（一科）一個池

好處：交呢班、上呢班，家長同收銀直覺一致；兩科剩餘分開，唔會「交英文卻被數學扣」。

壞處：中文請假＋數學加堂必須搬 1 堂，否則一科剩、一科欠。轉科都要搬。前線為 8＝8 會唔入紙。

### B — 擬定：一個學生（同一學年）一個池

好處：上述 8＝8 自然成立，唔使搬堂；退讀 A、繼續讀 B，剩堂自動留俾 B；工程唔使維護「轉科搬池」。

壞處：單上寫「中文 4 堂」唔再保證只用於中文；同時讀兩科時，前線要改用「呢個人本月總共要扣幾堂」去收，唔好再分科各催 4 堂。欠堂時唔知「欠邊科」，只知「呢個人欠堂」。

### 擬定（請評呢個，唔係純 A 或純 B）

**點名紙、報讀、請假、加堂：跟 A（分班）。**  
**扣堂剩餘：跟 B（按人、同一學年共用）。**

前台可以唔搬池；唔可以唔做請假／加堂入紙。


## 6. 擬定流程

```
報讀某班
  → 就讀中
  → 該學年若未有池：鑄一個空池（學生 × 學年）
  → 有排程：為該班堂次建宣告 → 該班點名紙見名
  → 不加可用堂數

開排程／加堂
  → 只為就讀生（加堂則指定學生）建宣告、上紙
  → 不加可用堂數

收款登記（學費堂數 N）
  → 總池 remaining +N
  → 單上可寫班別，只為對帳／統計
  → 收銀建議＝本月所有就讀班會扣嘅堂（加堂計入；事假／病假唔計）− 總剩餘

退讀某班
  → 該班未來堂從點名紙除掉
  → 總池不清空；其他仍就讀嘅班繼續扣同一個剩餘

點名
  → 計費狀態（現場、no show、錄影、加堂出席等）：總池 −單位
  → 事假／病假：池不變，紙上仍有名
```

試堂另路：確認學費單後先上紙；**唔混入**呢個正規總池。


## 7. 用日常例子對一次

學生報中文＋數學，月初交 8 堂。

| 步驟 | 紙 | 總池 |
| --- | --- | --- |
| 報讀兩班、排程已開 | 兩班紙都有名 | 0（未收款） |
| 確認收款 8 堂 | 不變 | 8 |
| 中文請 1 堂（唔補） | 中文紙見名、預填事假 | 仍 8（點名事假後仍 8） |
| 數學加 1 堂 | 該堂數學紙見名 | 出席後 7 |
| 其餘 3 中文＋4 數學照上 | 照點 | 再扣 7 → 0 |

月內計費消耗 8，同收款 8 對齊。  
若第 3、4 步唔入紙：池可能仍對到 8，但老師名單錯 — **呢個方案唔接受。**
