## 1. 一句

**大方向同意顧問。** 「紙分班、池按人」要成立，必須係：**一個結餘 + 每筆流水帶班／堂次**；池嘅邊界係**收費層級**（同價小組／一對一／試堂／學年），唔係科目名。

先前簡報寫「一人一池」太粗。正確說法係：**同一學生、同一學年、同一收費層級，共用一個剩餘。** 中文＋數學（同級同價小組）共用；一對一、試堂、暑期包唔共用。


## 2. 同意（跟顧問）

| 顧問句 | 點解跟 |
| --- | --- |
| 結餘一個數；流水必須有班別＋堂次 | 否則 8＝8 對到數，但「中文請咗未、數學加咗未」永遠答唔到。現役已有扣堂事件表，合併池時**唔可以**把流水收成只有一個總數。 |
| 剩餘 UI 唔好顯示「中文剩 X、數學剩 Y」 | 嗰兩個數唔真實（池已共用）。前線一見就會返去催「數學補 1 堂」。 |
| 收據可仍分班寫堂數；角色改成會計行，唔再等於「只能上呢科」 | 同而家開單習慣相容。要加註＋統一話術，否則家長投訴只係時間問題。 |

對帳報表（每月逐生：收款堂數 vs 扣堂明細 vs 剩餘）：**同意做**，因為已觀察到前線會為 8＝8 唔入紙。唔同意把它當成改池結構嘅阻擋條件——但 `2627` 真班試行時，最少要有可查嘅逐生對帳（唔使一開始就好似營運總覽咁靚）。


## 3. 反駁／收窄

**（1）「一人一個池」唔好照字面做。**  
顧問自己用「收費單位」修正咗。工程跟**收費層級**，唔好做成試堂、一對一、小組全部同一個剩餘。

**（2）「唔同分班剩餘」唔等於「畫面唔准出現班名」。**  
剩餘只有一個數。**明細可以分班**（本月中文扣 3、數學扣 5；邊張單入咗幾堂）。顧問原文係呢個意思；避免執行時做成老師／前台連「呢堂邊個科」都睇唔到。

**（3）強制分池，唔好用「呢張單折扣後單價」。**  
半價、兄弟優惠會令實收 ÷ 堂數變咗，但堂仍然係同一級小組單位。分池應跟**班嘅產品／價目層級**（小組常規 vs 一對一 vs 試堂），唔跟該行折後平均價。否則優惠會誤拆池，8＝8 又壞。

**（4）「每生每科試堂次數上限」唔入今次。**  
政策上合理，但同池結構無關。另開題，唔擋改池。

**（5）正規學年剩堂自動結轉到下學年 — 未同意。**  
「剩堂跟人走」係**同學年內**轉班／轉科。學年硬閘（暑期包唔入正規、`2627` 唔同 `2728` 混）仍然有用。  
若 `2627` 尾剩 3 堂自動入 `2728`：請假不扣堂會變成**跨年儲蓄**（月月請 1 堂假、加另一科，再把未用帶去下年）。呢個可以係產品句，但要你明示，唔好當技術默認。  
暑期 `26SM` 到期、唔結轉：同意作為預設建議。

**（6）退學後 6–12 個月作廢 — 方向同意，月數未定。**  
常規唔退費，作廢＝沒收剩餘、唔退錢，要寫得啱先好對家長講。期限你定。


## 4. 收斂後模型（跟咗先准改 code）

三層不變：報讀分班；紙分班（宣告）；**結餘按「學生 × 學年 × 收費層級」。**

| 層級（例子） | 同池？ |
| --- | --- |
| 同級小組中文＋數學（同標準單堂價） | 是 |
| 小組 vs 一對一 | 否 |
| 正規 vs 試堂 | 否 |
| `2627` vs `26SM` | 否 |
| 連堂一格 | 同小組池，扣 2 單位 |

流程（小組層級）：

1. 報讀班 → 就讀；該層級未有池則鑄空池。排程／加堂只上紙，唔加剩餘。  
2. 學費單堂數 → 該層級池 +N。單上仍可寫班別。  
3. 收銀建議 → 該層級本月所有就讀班會扣堂（加堂計、事假／病假唔計）− 該層級剩餘。  
4. 計費點名 → 該層級池 −單位；流水記班＋堂次。事假／病假唔扣。  
5. 退讀一班 → 只清該班未來紙；池唔清。  
6. 試堂 → 獨立池；只准試堂堂次扣；轉正唔搬入小組池。

明確唔做：前台轉科專頁；池有剩就自動出現喺未報讀／未加堂嘅紙；今次唔做收入認列／欠費門禁／常規退費。
