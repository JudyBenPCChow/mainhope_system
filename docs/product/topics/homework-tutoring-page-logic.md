## 一句

功輔各頁問的時間不同：概覽「今日」與管理層「本月當值」看日曆今天／本月；編更／報更看籌備月（預設下月，可切回當月）。休學不計該月月費；缺日數檔顯示未設定。

## 已修

1. **概覽「今日」**不再跟月工作表選月；另載日曆當月當值。
2. **管理層「本月當值」**獨立載入日曆當月，並可切月。
3. **編更／報更**仍預設下月；老師報更可切月補當月。
4. **外星人**行政編更月與管理層本月當值不再共用同一份 `dutyDays`。
5. **日期鍵**查找當值／報更／放假一律走 `toDutyMdKey`（ISO、`09/02`、`9/2`）。
6. **開頁只讀**：`fetchHomeworkRosterMonth` 不再 `insert`；儲存／發布編更才 `ensureHomeworkRosterMonth`。
7. **報讀表「生效月」**改稱「報讀月份」（仍為報讀日的年月，不是覆蓋起始月）。
8. **休學不計該月月費**，直至報讀改回就讀中。設定處：學生詳情 → 報讀班別 → 狀態改為「休學」（功輔頁顯示「暫停」）。月費表與概覽未繳只計在籍。
9. **缺日數檔顯示「未設定」**，不以四日計價。
