## 一句

系統關聯不該活在職員可編的備註裡。全班同一日的補回，真源改為指向取消堂的外鍵；`remarks` 只留人手文字。歷史備註標記保留作檔案，不准刪。一人一個去向的補回記在請假紀錄，不記在這條外鍵。後句仍是討論方向，見「未決」。

### 直接改日期，與取消後再開

兩種都讓全班改在另一天上課。2026-11-16 只決定「要有改日期」，沒有取消另一種。

| | 直接改日期 | 取消原堂，再開新排程 |
| --- | --- | --- |
| 日曆 | 原日那一格沒有了，只剩新日 | 原日仍在，狀態是已取消，可寫原因；新日多一堂 |
| 是不是同一堂 | 是。編號不變，已有的外鍵也不變 | 否。新的一列，要再寫一次補哪一堂 |
| 已點名 | 出席跟著走到新日 | 原日出席要選擇保留或刪除；新堂重新點名 |
| 試堂 | 掛在這一堂的試堂跟著到新日 | 取消時未完成的試堂會被取消，不會自動搬到新堂 |
| 別人調來這一堂 | 那筆請假仍掛在這一列 | 取消時那些請假回到待安排 |
| 單堂報讀 | 仍綁同一列 | 要改掛到新的一列 |
| 跟進「這次取消補了沒有」 | 沒有取消紀錄 | 有。新堂寫上補回關係後才算已安排 |
| 暑期屬於哪一期 | 跟新日期 | 跟被取消那一堂的原日期 |

原日不必留下取消紀錄、且尚未點名時，改日期較省事。原日必須留成已取消，或當天已經點過名時，用取消再開。兩種都不需要逐人請假。這段是說明，不是未決以外的新規則。

## 討論方向（未覆核，不當開工規格）

以下是 2026-11-16 依用戶描述整理的方向。用戶尚未逐項確認。未決 U2–U4、U7 就是要不要採納這一段。

### 用戶描述的現實

全班在同一個原本沒有課的新日補回，是理想情況，不是常態。同一個老師請假可以同時出現：

1. 學生 A 坐進老師已有的排程甲（不是 A 的班），學生 B 坐進排程乙（不是 B 的班）。
2. A 坐進排程甲；B 不補回，用戶口述「下月交少一堂學費」（學費是否少收見未決 U6，不要寫進排程規則）。
3. A 與 B 在同一個新日補回；C 坐進老師已有的另一堂。
4. 兩班、兩堂一起取消。A、F、G 在同一個新日補回；B、C 坐進老師已有的堂；E 不補回。

### 建議的記法

每個應到生只結一種去向：坐進已有的另一堂、參加一堂新開的課、不補回，或看錄影。

- 已有的甲堂、乙堂仍是原班的正式課。只在該生的請假寫調堂到該堂。不要在那些排程上填外鍵。
- 新開的一堂只放當天要來的人，可以來自不同班、不同的被取消堂。不要填「補哪一次取消」，因為一欄只能指向一次取消。
- 全班剛好都能在同一個新日回來，才是現在的「安排補堂」：一堂取消、一堂補回、全班上點名紙，並填外鍵。
- 某次取消算處理完，是看每一位應到生都已有去向，不是只看有沒有一條全班外鍵。

請假紀錄已有的欄位夠用：`schedule_id` 是原本被取消或請假的那一堂，`makeup_schedule_id` 是實際去上的那一堂，`makeup_type` 為待安排／調堂／錄影／不補回。

### 每人一筆是否可行

可行，而且一半已存在。學生請假本來就是每人一筆。老師請假並取消時，已為每位應到、當天還沒有請假的學生建立「老師請假／待安排」；已有請假的不重複建立；本來調來這一堂的人退回待安排。

不順的是全班「安排補堂」不寫這些請假，跟進表只認 `makeup_of=`。建議改成：一次取消只產生每人一筆請假；可以勾選多筆一次安排（開一堂只收被勾的人，或一起調去同一堂已有的課）。全班同一日是把該次每一筆都勾上，不是另一套資料。

建議不要建請假的三種情況（未覆核）：

- 代堂。課堂照常，只換老師。
- 直接改日期。原日不留成取消。
- 該生當天已有請假。沿用原筆。本來調來這一堂的人退回待安排，不另建一筆。

同時必須成立：新開或調入的那一堂，點名紙只出現被勾選的學生；扣堂算回原本那一班，不算宿主班。這是現有系統還沒收口的部分。

### 班內只有一位學生

建議、未覆核：專科班走請假，不因只剩一位就讀生就取消排程。取消表示這一堂不舉行；請假表示這一堂仍在、這個人不來。就讀中只有一人時，當天仍可能有調入的學生或試堂。若事前確定沒有人會來、要放開老師和課室，在請假之外再取消，兩件都留。

私人課程一對一沿用營運指引：雙方已約定新日就直接改日期，不建請假；新日未定才取消原堂並留一筆待安排。不要調去別班的專科堂。見 [`makeup-special-cases.md`](./makeup-special-cases.md) Y01、[`ops-guide.md`](../../year/2627/ops-guide.md) 第 6 章。
