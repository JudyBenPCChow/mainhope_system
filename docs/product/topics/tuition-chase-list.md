### 0.1 採納（寫入方案）

| 問 | 決定 |

| 1 單位 | **常規第 N 期**正確，不退回曆月。對家長可輔以期名＋首尾上課日（例如「常規第一期 · 9/1–10/3」），不要寫成「9 月學費」。追收頁（期）與逾期罰款（曆月）是兩套週期；發佈時前線指引加一句話術。 |
| 2 一次過可收 | 公式維持本期＋下期合計，但**降為次要說明**。主強調「本期要交」。文案：「可一次收齊 N 堂（兩期，非硬性）。」 |
| 3 隊列 | 工作隊列維持互斥。篩選卡顯示互斥人數，並並列**全校宏觀**（本期要交人數、下期要交人數，可重疊）。預設 chip「現在要追」。 |
| 4 收款建議 | **不**把收款引擎全面改成期數（功輔覆蓋月、罰款頻率的曆月是真主人）。行級建議不要用「全組別會扣 − 池餘」（同一組兩班會重複計算）；改為該行班別在**本期**的未扣排程數、**不減**尚餘。池缺口由摘要的期數 chase box 顯示。功輔行維持曆月。未改行級前，兩套口徑 caption 分開。 |

| 6 用詞 | 鎖死兩組：**動詞**（本期要交／下期要交／一次過可收）＝收錢，0＝不用收；**名詞**（尚餘可扣堂數／已扣／還會扣／會扣／已收款堂數）＝堂數流水。畫面用全名「尚餘可扣堂數」。 |

| 9 範圍 | 功輔、僅暑期不進預設名單。無期數表時空狀態，不要假裝常規第一期；空狀態註明功輔不適用本頁。缺池資料的組別不可當尚餘 0（假欠）。 |

## 1. 發起人目標（多輪整理）

### 1.1 最初要解決的前台問題

幫助前台快速找出在讀生：

- **這一期**學費是否繳清（初版口頭說「本月」；其後改為常規第 N 期，見 §1.3）。
- **下一期**要追多少堂。
- 一眼分開**已交／未交**，並知道自己要追收多少學費。

不限於九欄總表。展示形式、架構都可以改，**以能協助追收為準**。

每列按下後，**右側詳情列**要能說明該組別的**款項與扣堂**，方便前台對家長解釋，不必另外「展開」。

### 1.2 查詢與隊列

- 按**學生 × 已繳堂數組別**查詢（同一級專科班共用一列；私人課程分開）。不可用總尚餘去減總要上。
- **建議收／一次過可收＝本期要交＋下期要交**（初版曾用「月」表述）。畫面降為次要，見 §0.1 Q2。
- 工作隊列三組：**現在要追／下期要追／已預繳**；已預繳不預設列出（chip 才顯示）。名單用篩選 chips＋單表，不是三組可摺疊卡片。
- 點列開**共用右側預覽**（款項＋已扣／本期還會扣／下期會扣）。
- 「**開完整詳情**」進入**學生詳情**，並有學費追收子頁；內容對齊預覽：尚餘／本期／下期、款項、扣堂。權限同繳費。

### 1.3 單位：全頁常規第 N 期，不是曆月

行政側有工作隊列與右側預覽。**全頁不以曆月為單位**，改以補習社**常規第 N 期**（2627 營運指引附件甲）為單位——是邏輯與文案都改，不是只改標題。

收費常說「約每月四堂」，但附件甲是「每一星期幾各四堂」，假期與日數會令某曆月多於或少於四堂；期與期的上課日可以交錯（例如第一期星期六可落在 10 月 3 日，第二期星期二已由 9 月 29 日開始）。用月份窗會算錯。

亦不按**收款日／覆蓋月**把專科學費標成「某月學費」（見 §2：8 月交 9 月；9 月一次交 9–11 月）。尚餘＝已繳未扣。

### 1.4 預覽必須能解釋「為什麼」

只知道「要／不要收」不夠。前台還要在**同一塊右側詳情**（不必另展開）看懂原因與證據：

- 是否因為本期已經收過錢（尚餘剛好覆蓋還會扣）
- 是否因為**先前已繳未用完**（扣完本期後尚餘仍 > 0）
- 是否因為本期**事假／病假不扣**，所以沒有還會扣
- 是否因為本期**已扣完**或沒有排程
- **尚餘多少堂**（已繳而未扣）；標籤用「尚餘可扣堂數」並有說明（Tooltip）
- 本期／下期**共扣堂數**＝已扣＋將扣／會扣（消耗），與「要交」分開
- **已收款**有哪些單、共多少堂
- **已扣**（本期已點名且計費）與還會扣、下期會扣的排程
- 尚餘為負時用**淡紅底**醒目，並用人話說明已上課未付款

### 1.5 本頁做什麼、不自動做什麼

本頁協助前台**看**與**決定收多少堂**。步 4 仍要：抽樣對庫（宣告＋本期點名＋下期排程）後再收斂。

不做：不自動出單、不發 WhatsApp、不取代 AI「追收學費摘要」、不改終身追收 RPC、不把暑期堂／未繳仍上點名紙當成缺陷。未要求則不 commit／PR。

## 4. 計算口徑

**列的單位**：學生 × 已繳堂數組別。

**時間單位**：分桶用附件甲**上課日集合**，不可只靠期名的起迄曆日（`from`／`to`）。

本期／下期：

1. 取**仍有上課日 ≥ 今日的最早一期**為本期；其下一期為下期。**不要**用「今日落在哪一期的日期集合」：期與期上課日交錯（例如第二期星期二 9/29 已開始、第一期星期六 10/3 尚未完；第三期星期二 10/27 已開始、第二期星期日 11/1 尚未完）時，會把尚未上完的那一期提早丢掉。前台按期數追收，十月仍要追含 11/1 的常規第二期，同時用「下期要追」收第三期。
2. 今日早於第一期最早上課日 → 第一期為本期（學年尚未開始，方便八月收九月）。同一條「仍有上課日 ≥ 今日」已涵蓋。
3. 學年已完（已無任何 `date ≥ 今日`）→ 兩期皆空。
4. 本學年沒有期數表（例如暑期學年代號）→ 兩期皆空，畫面走空狀態，不要回退成「常規第一期」。

單測至少覆蓋：2026-09-26（中秋，應留在第一期）、2026-09-29（第二期已開始但第一期未完，應留在第一期）、2026-10-27（第三期已開始但第二期未完，應留在第二期）、2026-12-26 與 2027-01-01（聖誕／元旦窗，不可跳到第六期）。

每組別：

| 名稱 | 定義 | 前台語意 |
| --- | --- | --- |
| 尚餘可扣堂數 | 該組別已繳而未扣（可負） | 現在袋裡還有多少堂 |
| 本期已扣 | 本期上課日、已點名且計費 | 本期已經扣了多少 |
| 本期還會扣 | 本期未取消排程、該生有 **active 宣告**、且尚未有點名列。連堂按班別堂數（2 格＝2 堂）。含補回／加堂與調堂（宣告可在別班，同一已繳堂數組別）。單堂只計已綁的堂；不要用該班全部排程。退讀班殘留的 `enrollment_auto` 不計。 | 本期還會再扣多少 |
| 本期共扣堂數 | 本期已扣 ＋ 本期還會扣 | 本期一共會扣多少（消耗，不是要交） |
| 本期要交 | `max(0, 本期還會扣 − 尚餘)` | 本期還要不要收、收多少堂。尚餘為負時＝還會扣＋已上課未付款堂數 |
| 扣完本期後尚餘 | 尚餘 − 本期還會扣（可負） | 扣完本期袋裡剩／欠多少 |
| 下期會扣／下期共扣堂數 | 下期未取消排程、該生有 active 宣告（私人課程無宣告則用該班排程）。 | 下期一共會扣多少 |
| 下期要交 | `max(0, 下期會扣 − max(0, 扣完本期後尚餘))` | 下期還要不要收、收多少堂。不含舊欠（舊欠已在本期要交） |
| 一次過可收 | 本期要交 ＋ 下期要交 | 若家長願意可一次收的堂數（次要，非硬性） |

隊列：本期要交 > 0 → **現在要追**；否則下期要交 > 0 → **下期要追**；否則 **已預繳**。尚餘為負時本期要交必 > 0，不會標成已預繳。

缺池：讀不到該組別已繳堂數列 → **不列為要追**，或列「未有結餘資料」且不計入要交堂數。不可把缺資料當成尚餘 0（假欠）。私人課程班沒有學年欄、2627 亦尚未鑄私人池：預設名單仍要列出在讀私人課程，結餘顯示未有資料。

已收款堂數：只計學費行（`lesson_count ≥ 1`）。優惠行、罰款行不入堂數加總。

例：尚餘 4、本期還會扣 4、下期會扣 4 → 本期不用收、下期要收 4、一次過可收 4。  
例：尚餘 0、兩期各還會扣 4 → 本期 4＋下期 4，一次過可收 8，隊列為現在要追。  
例：尚餘 −2、本期還會扣 0、下期會扣 4 → 本期要交 2（已上課未付款）、下期要交 4，隊列為現在要追。

## 5. 頁面、功能與設計

### 5.1 學費追收名單 `/TuitionChase`

- **入口**：行政側欄「收款登記」子項「學費追收」。角色 admin；外星人側欄收費組亦有。權限同收款（可出單／確認已收）。
- **頁頂**：標明本期／下期名稱（期名＋首尾上課日）。註明本期＝仍未上完的最早一期。
- **篩選卡**：人數數字（現在要追／下期要追／本期要交人數／下期要交人數）＋ chips（預設「現在要追」；另有下期要追、未有結餘資料、已預繳、全部）＋搜尋。已預繳改由 chip 顯示，不另用隱藏橫幅。
- **單表**：學生｜組別｜本期要交｜下期要交｜尚餘可扣堂數｜收款。組別欄直接列出該生就讀中班別的**班別編號**（`course_code_full`）與**報讀班別**名稱；多組別時可點該組班別開右側。一次過可收不列在表上。
- **範圍**：預設本學年就讀中專科／私人；「顯示更舊」只擴大名單，欄位數字仍鎖本學年。
- **空狀態**：沒有期數表、或兩期皆空時，說明「本頁只適用常規專科班／私人課程的期數追收；功課輔導班是月費，請走收款登記。」不要顯示成常規第一期的要交數。

流動裝置無右側欄，改為點列進入同一套詳情（可返回名單）。

### 5.2 右側預覽欄（桌面）

與學生／班別預覽同一條 `RecordPreviewRail`。點列即顯示該組別，方便對家長解釋。

組別標籤（右側預覽／多組切換）須能看出錢包範圍，例如「專科班（中一）· 中文、數學」。名單組別欄改列班別編號與報讀班別，不靠這句錢包標籤。

**要收（一眼：已交／未交、要追多少）**

- 本期要交（0＝不用收；若含已上課未付款，說明句寫出 N 堂）
- 下期要交
- 一句為什麼（不用收要分開：尚餘剛好夠本期／先前已繳未用完／本期請假不扣／本期已扣完／本期沒有排程）。放在要交數字正下方。名單「不用收」下方同步短因，不必點進右側才知道。
- 一次過可收：次要說明句，不是第三主格。「可一次收齊 N 堂（兩期，非硬性）。」

**已繳與扣堂（為什麼；對家長可講的證據）**

- 尚餘可扣堂數：全名；Tooltip「此組別已繳而未扣。同一級專科班共用，私人課程分開。」負數淡紅底，並用人話「已上課未付款 N 堂」。header 已顯示則統計格不要再重複。
- 本期已扣、本期還會扣（可一行）；兩者合計即本期共扣堂數
- 下期會扣（下期共扣堂數）
- 已收款堂數（該組學費行堂數加總，**含已扣**，≠ 尚餘）
- 學生詳情分頁另顯示「扣完本期後尚餘」
- 本期還會扣／下期會扣下方：**科目小計**（英文 4 堂、數學 4 堂）

**清單（解釋用；計數格不收）**

預設收合「顯示明細」。學生詳情分頁見 §5.3，不摺疊、不用本預覽版面。

- 已收款：日期、收據號、金額、班、堂數；連到繳費紀錄。只列學費行。
- 本期已扣：日期、時間、班、堂數、點名狀態
- 本期還會扣：尚未點名的排程；另註事假／病假不扣堂數
- 下期會扣：下期排程

底部：收款登記；**開完整詳情**→ `/Students/:id?tab=tuitionChase`（數字與用詞對齊本預覽，版面見 §5.3）。多組別用標籤切換。

### 5.3 學生詳情分頁 `?tab=tuitionChase`

數字、用詞與公式與右側預覽相同（尚餘／本期／下期要交、款項、扣堂），**版面跟學生紀錄頁**，不再共用 `TuitionChasePreviewPanel`。權限同繳費。

- 頂列：本期／下期名稱（期名＋首尾上課日）＋隊列標籤；右側收款登記。
- 一句說明：報讀班別的「尚差堂數」是全學年已繳對已綁排程，**不是**本期要收。
- 多組別一次列出（報讀卡慣例），不用 pill 切換。從名單帶入 `?pool=` 時該組加框並捲入視窗。
- 每組：要交摘要用 `dl` 卡（本期要交／下期要交／尚餘可扣堂數＋一句為什麼＋一次過可收次要句）；堂數流水第二張 `dl` 卡（已扣／還會扣／會扣／已收款堂數／扣完本期後尚餘＋科目小計）。
- 已收款用繳費卡縮小版（日期、收據、金額、班、堂數），連到繳費紀錄；不作廢／列印。
- 本期已扣／還會扣／下期會扣用上課紀錄那種表（日期、時間、班別可連班別頁、堂數、點名狀態僅已扣），不摺疊。還會扣表下註事假／病假不扣堂數。

### 5.4 收款登記 `/Payments` 學生摘要

選學生後，摘要顯示同一套期數：本期／下期要交、尚餘（chase box；池級缺口以這裡為準）。

行級堂數自動建議（專科／私人）：該**行班別**在本期的未扣排程數，不減尚餘、不加總同組其他班。功輔行維持曆月月費。未改行級前，caption 須寫明建議仍是曆月／舊口徑，避免與 chase box 的「0＝不用收」打架。

## 6. 用詞（畫面）

兩組不可共用標籤：

- **動詞（收錢）**：本期要交、下期要交、一次過可收。0＝不用收。
- **名詞（堂數流水）**：尚餘可扣堂數、本期已扣、本期還會扣、本期共扣堂數、下期會扣、已收款堂數。

| 用 | 不要 |
| --- | --- |
| 尚餘可扣堂數 | 只寫「尚餘」而無說明；權益池；全科目通用 |
| 已上課未付款 N 堂／已超用 N 堂（負數說明） | 過往欠堂；arrears；透支；資金充足 |
| 本期／下期共扣堂數（已扣＋將扣／會扣） | 把消耗叫做「N 月要交」或「本月要交」 |
| 本期要交／下期要交／一次過可收 | 與共扣堂數混用同一個標籤 |
| 已繳、已扣 | 已付、已上 |
| 常規第一期…常規第十期；期名可附首尾上課日 | 裸寫「第一期」；用月份當期名；「9 月學費」 |
| 專科班、私人課程、功課輔導班 | 把功輔當專科扣堂 |

發佈時同步 `docs/meta/TERMINOLOGY.md` 與 `.cursor/rules/terminology.mdc`（學費追收、本期要交、尚餘可扣堂數、一次過可收、常規第 N 期）。前線指引加：追收頁講收幾多堂，罰款是另一套按曆月的規則；尚餘以畫面為準，遲點名跟進老師；共用組別話術見 Q7。
