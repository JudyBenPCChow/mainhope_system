## 3. 第二位多出、值得吸納

**課程組別。** 顧問二寫「學生 × 常規學年 × 同價同規則課程組別」，比「一人一池」同單講「收費單位」更可執行。組別同時睇價錢**同**服務規則（時長、扣堂單位、取消／退款承諾），唔單睇科目名。

明學起步組別（已拍板）：


| 課程組別                         | 共用？            |
| ---------------------------- | -------------- |
| 小組專科（同一級、同一標準單堂價同規則，例如中文＋數學） | 是              |
| 私人課程（一對一／一對二）                | 否，另組           |
| 功課輔導                         | 否，另組（價錢／規則唔同時） |
| 試堂                           | 否，另組           |
| 暑期 `26SM` vs 正規 `2627`       | 否              |


**更正＝新交易。** 剩餘唔好無事件直接改。作廢／調堂走沖正或調整列（同而家 G2 方向）。

**一對二、課堂時長、服務承諾不同。** 併入「唔同規則就唔共用」。分池跟班嘅產品組別，唔跟折後單價。

顧問二「收據三行」**產品唔跟**：單維持分科開，唔印共用工程句（D11）。

## 6. 對你回覆嘅釋義（工程用）

### D3 — 入池同優惠

有，已拍板。母題 [`summer-enrollment-roster-consistency.md`](./summer-enrollment-roster-consistency.md) **§4.11**：

- 入池只睇學費行 `lesson_count`
- 金額／優惠只影響錢，唔另計堂數
- 遲交罰款不入池

同你講「入池唔考慮優惠，只考慮堂數」完全同一句。D3 其餘半句仍然有效：入**邊個**池跟班嘅課程組別（小組 vs 一對一 vs 試堂），唔好用折後平均價去拆池。

### D8

「3個月」釋義為：**完全退學（該學年該組別再無就讀）當日起計 3 個月**作廢，唔退錢。唔再加「先等學年結束」。若你本意係學年結束後先再等 3 個月，改呢句。

### D9 — 三個數

| 畫面／對帳用詞 | 意思 |
| --- | --- |
| 已收堂 | 已**確認收款**嘅學費堂數（單上 `lesson_count` 加總入池）。唔係「已排程」、亦唔係未確認嘅單。 |
| 已扣堂 | 點名屬**計費**狀態嘅消耗（現場／no show／錄影等）。事假／病假唔計。明細可分班。 |
| 剩餘 | 已收 − 已扣 ± 更正調整。可負。 |

「已繳」若係指錢，唔等同已收堂（優惠會令錢同堂分開）。對帳用**堂數**。

### D10 — 若唔經宣告，仲有咩入口

而家／舊路徑可以令紙上有人、但無宣告：

- 用日期推算報讀期數上紙（舊暑期邏輯）
- 點名紙直接加名／直寫 `attendance_details`
- 補堂 `makeup_of` 繼承（`26SM` 止血；`2627` 唔用）
- 只改報讀、未為該堂建宣告

D10 即係 `2627` 禁止以上捷徑：紙上有名 ⇔ 有 active 宣告。

### D11

跟你：家長單**唔改**。分科分行照收。共用係後台結餘，唔印上單。切 `2627` 池結構**唔再等**收據改版。
