## 6. 排課核心規則

### 6.0 全校硬約束（2026-07-31 追加）

| 規則 | 說明 |
| --- | --- |
| **禁最後一節** | 唔排 **20:15–21:30**（slot 9）；最遲 **19:00–20:15** |
| **連堂休息** | 同一老師最多連續 **2** 堂，之後必須空至少 **1** 格 |
| **全日上限** | 同一老師同一日最多 **5** 節 |
| **功輔課室** | 功課輔導固定 **17D**（平日全日） |
| **兼職密排** | 除 **Katie（全職）** 外，同一日相鄰兩堂之間最多空 **1** 格（唔好隔兩格或以上先再上）；方便上完離開 |
| **開會空檔** | **Mark／Christine／Katie** 須預留一個**非星期日**共同得閒時段（固定開會用，未必每週開） |





### 6.1 學生不撞科（最重要）

**同年級的不同科目絕不能放在同一時段**。例如 S1 的中文和數學不能同時在星期一 slot 6，否則學生無法同時報讀兩科。

### 6.2 同日順接（盡量）

同一年級在**同一日應有不同科目順接**（連續時段），方便學生同日連上。例如：

- S1 星期一：slot 6 中文 → slot 7 數學 → slot 8 英文



### 6.3 每級分佈

每級嘅中英數應分佈在 **2-3 個不同日子**，不要集中在一天。

### 6.4 不重疊資源

- 同一老師不能同時段教兩班
- 同一課室不能同時段有兩班
- 同一學生不能同時段有兩科（避免同年級不同科同 slot）
