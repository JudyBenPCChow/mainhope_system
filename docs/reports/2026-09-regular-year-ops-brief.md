## 1. 學年定位（9 月常規）

| 項目 | 值 |
| --- | --- |
| 類型 | **正規學年（常規）** |
| label | `2627`（`YYZZ` 四年數字） |
| 課程模式 | `courses.course_mode = regular` |
| 約略時段 | **2026-09-01 → 2027-06-30** |
| 期數字典 | **唔用** `academic_year_periods`（暑期兩期制不適用） |
| 前後銜接 | `26SM`（2026-07-01～08-31）→ **`2627`** → `27SM`（2027-07～08） |

**label 推導：** 開課／學年起始月落在 9 月–翌年 6 月 → `YYZZ`。例：2026-09-01 → `2627`。

**可編輯：** 自 `26SM`（2026-07-01）起前台可編輯；`2526` 及更早對部分角色唯讀。規劃 `2627` 班務屬可寫範圍。

**曆面提示（非政策，僅方便排堂）：** 2026-09-01 係星期二。學年 `start_date` 固定 9/1，**唔等於**「第一堂一定喺 9/1」——實際首堂日由各班排程決定（見 §8 缺口）。

## 3. 學費與「每月約四堂」節奏（對時間表有影響）

| 項目 | 正規學年慣例 |
| --- | --- |
| 報讀 | 常為報足全期（或單堂） |
| 收費實務 | **按月**繳；常見一次約 **4 堂**＝一個月 |
| 收款工具現況 | `/Payments` 堂數包；UI 預設一次收 4 堂。舊「每月學費」頁已下線 |
| 例子 | 報讀九月中文班 → 先交九月約四堂學費；十月理論上第一個禮拜應續交 |

**對開班規劃嘅含義：**

- 小組課常見模型係**逢星期同一時段上一堂** → 一個曆月約 4 堂，對齊學費包。
- **連堂**＝一節排程佔連續兩格；點名連堂扣 **2 堂**（兩個 schedule 各一列）。連堂班若每週上一次連堂，月學費堂數會按「節」而非「日」累計——方案要標明係單堂格定連堂。
- 逾期罰款（該曆月第 2 堂仍未交 → HK$50；第 3 堂起禁入）**適用正規、唔適用暑期**；系統尚未強制，前台人手把關。規劃時間表時可忽略執行細節，但勿假設暑期式「一次收齊整年」。

## 4. 班別類型（時間表兩套邏輯）

| | 小組課 `class_kind=group` | 一對一 `class_kind=private` |
| --- | --- | --- |
| 入口 | 班別管理 → 詳情 | `/PrivateTutoring` → 詳情 |
| 排程 | **固定**星期／時段／課室；可批量由班別規則產生堂次 | **無**固定逢星期；單次／週期／連堂「預約上堂」 |
| 9 月開班時間表主戰場 | **係**——固定週期表 | 多半按需求預約，唔係一次性全校固定表 |
| 主責老師 | `classes.teacher_id` | 同上 |
| 當日老師 | `schedules.teacher_id`（代堂改呢度，**唔改**主責） | 同上 |

判定：`class_kind` 優先；班名含「一對一／單對單」後備。

**代堂鐵則：** 偶發／輪流代課只改該堂 `schedules.teacher_id`；算堂數／薪資看排程老師。規劃「邊個教邊個 slot」時以主責為基線，代堂唔係開班方案本身。

## 6. 課程／班別編碼與定價慣例

**班別顯示碼**（`classes.course_code_full`）：

```text
學年-科目代碼+年級碼+三位種子-班號
例：2627-CHIS4001-A
```

- 學年段：`2627`
- 年級碼：小一–小六 `P1`–`P6`；中一–中六 `S1`–`S6`
- 班號：如 `A`、`B`…
- 科目代碼：見 `src/lib/courseCode.ts` 之 `SUBJECT_TO_COURSE_ABBR`（中文 CHI、英文 ENG、數學 MATH、中史 CHIS、理科／選修等）

**學費快捷（阿Po／UI 慣例，港元／堂）：**

| 快捷 | 含義 |
| --- | --- |
| 275 | 標準單堂（初中常見） |
| 300 | 標準單堂（高中常見） |
| 825 | 其他快捷（唔等於「每月四堂總價」自動換算） |

實際以班別 `price_per_lesson` 為準。正規多用每堂價；暑期可有期數差異價，本檔不展開。

建立班別慣例順序：學年 → 科目 → 年級 → 課程 → 班號；再開固定星期／時段／課室／主責老師，再批量產生排程。

## 7. 規劃助手應遵守嘅輸出約束

運算多個開班時間表方案時，請：

1. **只針對正規 `2627`／小組課固定週期表**（一對一另案；唔好混入暑期兩期制）。
2. **每個班列最少包含：** 科目、年級（可多級）、逢星期、時段（標準格或連堂兩格）、建議主責老師（若未知則標 TBD）、建議課室（若未知則標 TBD）、單堂／連堂、建議 `price_per_lesson`。
3. **標明衝突檢查假設：** 老師池、課室池、學生需求係輸入定係未知。
4. **學費節奏：** 預設每週 1 堂（單格）→ 約每月 4 堂；若用連堂或每週多於 1 次，在方案註明對「月費約 N 堂」嘅影響。
5. **唔好發明政策：** 公眾假期停課表、首堂週慣例、容量上限、必開科目清單——若輸入未提供，列入「待營運確認」，唔好當已定。
6. **方案比較維度建議：** 老師負荷均衡、課室利用率、晚間 vs 日間、初中／高中分佈、同科多班錯開、連堂比例。
