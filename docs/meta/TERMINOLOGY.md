# 明學教育用語表

給**全體員工**查閱：公司用詞及其含義。寫對外說明、內部文件、向家長解說時，請用本表用詞。

畫面用語以本表為準。舊資料值（例如資料庫的「非注冊」、計糧 mode「兼職 HC」）不會改寫，畫面會顯示「註冊／非註冊」「人頭」。

介面與文件用語：**繁體中文**。  
更新日期：2026-08-16

---

## 1. 機構與自稱

| 術語 | 定義 |
| --- | --- |
| **明學教育** | 對外正式名稱／品牌（側欄、收據抬頭、WhatsApp、頁標題）。英文品牌 **MainHope**。簡稱可寫「明學」。 |
| **補習社** | 指本機構這類生意，或作為指引／政策的主語。例如：「根據補習社指引，前台人員應……」「明學教育是一所位於粉嶺的補習社。」 |
| **本社** | 指我們自己。例如：「聖誕假期期間，本社仍會開放校舍供學生自修。」 |
| **校舍** | 物理場地、建築物。課室在校舍內。 |
| **校曆** | 本社上課日與假期的曆表（系統頁仍叫「校曆」）。 |

請勿使用：明學補習社（當正式品牌名）、mingxue、明學院、本院、校方、本校、院方、院內、全院、學院校曆。請勿用「書院」「學院」稱呼明學本身（學生就讀中學的正式校名除外，例如英華書院）。

法律全稱（收據等）：明學教育有限公司 MAIN HOPE EDUCATION LTD.

## 2. 三種課程

三條產品線分開，不要混稱。

| 術語 | 定義 |
| --- | --- |
| **專科班** | 以科目為主、多人同班的小組課。通常固定逢星期同一時段上課。日常所說「專科班」即指此類小組課。 |
| **私人課程** | 獨立產品線：一位老師對一位或兩位學生，多按約定約堂，沒有全校統一的固定周曆。其下再分**一對一**、**一對二**。不要用「一對一」當所有私人課程的總稱；不要稱私人課程為專科班。 |
| **功課輔導班** | 獨立產品線，簡稱**功輔班**或**功輔**。按月與佔室安排，不屬專科。請勿稱「功課班」。 |

「專科」二字單獨出現時，只用於對照功輔（例如專科校曆與功輔校曆）。主科／副科／選修只適用於專科班：主科為中文、英文、數學；副科為初中科學；選修為高中物理、化學、生物、企會財、數學延伸。

## 3. 學年與報讀

| 術語 | 定義 |
| --- | --- |
| **常規學年** | 每年九月至翌年六月（例如 2627 即 2026 年 9 月至 2027 年 6 月）。內分**上學期**（九月至一月）、**下學期**（二月至六月）。 |
| **暑期** | 每年七月至八月（學年代號如 26SM）。報讀形式為第一期、第二期或兩期全報。 |
| **報讀**（常規） | 學生加入某一班的就讀安排。常規學年默認讀至該學年結束，不必再選「第幾期」。 |
| **單堂** | 事前說明只報指定的一堂或多堂、並非入讀該班；學費按標準單堂價。試堂不算單堂。除試堂外絕少使用。 |
| **常規第 N 期** | 專科班校曆上約四堂為一塊的分段（附件甲第一期至第十期），**不是**報讀選項。 |
| **暑期第一期／第二期／兩期全報** | 暑期的報讀包裝。與「常規第 N 期」不是同一回事；說明時請加「常規」或「暑期」。 |
| **退讀** | 結束該班的報讀。並非刪除學生資料。 |
| **轉班** | 轉到同科目的另一班。 |
| **轉科** | 轉到不同科目。 |
| **試堂** | 尚未正式報讀、先試上一堂。收費可為全價、半價或免費；須先完成收款登記並確認，該生才會出現在當日點名紙。 |

請勿把常規報讀寫成「全期報讀」或「報足全期」（舊畫面用詞）。請勿把常規學年稱為「正規學年」。

## 4. 學生狀態

| 術語 | 定義 |
| --- | --- |
| **註冊** | 是否為本社正式客戶（相對試堂或查詢）。 |
| **報讀** | 是否已加入某一班（一班一筆安排）。 |
| **在讀** | 現時至少有一班仍在就讀中。 |
| **活躍** | 近三個月內曾有報讀紀錄。 |
| **就讀中** | 某一班那筆報讀目前有效（不是學生身上的第四個標籤）。 |

有學生資料不等於已報讀某班；已報讀某班也不等於所有班都在讀。

## 5. 時間：格、堂、節、排程

| 術語 | 定義 |
| --- | --- |
| **格** | 時間表上的一格，時長 75 分鐘。格子可以是空的，不代表有課。 |
| **堂** | 某班的一次課，用來對帳、欠堂、已繳／已扣。可以欠學生一堂但尚未排定時間。 |
| **節** | 課堂進行時的單位，尤其用於連堂拆開（例如「連堂第 1 節」「只請本節」）。 |
| **課堂** | 泛稱，不指某一天。例如：「課堂上不得飲食。」 |
| **排程** | 系統上的上課安排。例如：「加入一個新排程。」 |
| **連堂** | 兩格相連、兩節、扣兩堂。 |
| **時間表** | 對外或全社公開的每周上課表。 |
| **課室** | 上課房間。現用：17D、17E、山案座、矩尺座、英仙座。17K 已停用。 |

## 6. 點名、請假、代堂

| 術語 | 定義 |
| --- | --- |
| **點名紙** | 該堂應到學生名單的畫面。 |
| **上紙／上點名紙** | 該生已交學費（或已確認的試堂單），點名紙上應該有其姓名。 |
| **已繳堂數** | 該科已入帳、可用的堂數。 |
| **已扣堂數** | 已按點名規則銷掉的堂數。拖欠＝已扣多於已繳。請勿稱已付／已上。 |
| **補堂** | 對應某堂已取消之後，用來補償的那一個排程。 |
| **調堂** | 學生原報讀 A 班，請假後改坐入另一時間（可能是 B 班）的某一節。 |
| **改期** | 同一班把該堂改到另一日（私人課程尤常用）。 |
| **代堂** | 只改該堂實際授課老師；班的任教老師不變。 |
| **任教老師** | 該班常任負責老師。 |
| **實際授課老師** | 該堂當日真正上課的老師。 |

請勿把補堂、調堂、改期當成同一個動作。請勿把代堂稱為代課。畫面「換主責」即更換任教老師。

## 7. 學費與單據

| 術語 | 定義 |
| --- | --- |
| **收款登記** | 在系統記錄一筆收款的動作。 |
| **收據** | 收款後發給客戶的紀錄（紙本或 PDF）。 |
| **繳費紀錄** | 已發出收據的一覽。 |
| **逾期罰款** | 常規專科班拖欠學費時，收款另收的港幣 50 元罰款（每科每月最多一次）。試堂、私人課程、暑期不適用。 |
| **追學費** | 系統上的堂數缺口提示（已扣相對已繳）。**不是**已經決定收 50 元罰款。 |
| **按月約四堂** | 收費節奏（逢星期上一班，一個曆月大約四堂），不是帳面欄位。 |

校舍假期期間本社沒有課堂。請勿說「停課」「休課」。**放假**專指員工放假。

| 術語 | 定義 |
| --- | --- |

| **人頭** | 點名或計糧時計算的人數。 |

## 10. 容易混淆、請分開使用

- 追學費 ≠ 逾期罰款 ≠「本社沒有任何課堂」
- 代堂 ≠ 更換任教老師 ≠ 開新班／轉班／轉科
- 報讀 ≠ 註冊 ≠ 在讀 ≠ 活躍 ≠ 就讀中
- 已扣堂數 ≠ 點名紙上有名
- 暑期第一期（報讀包裝）≠ 常規第一期（校曆分段）
- 報讀（入讀該班）≠ 單堂
- 專科班 ≠ 私人課程 ≠ 功課輔導班
