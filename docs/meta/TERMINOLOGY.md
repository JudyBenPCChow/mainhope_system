# 文案與稱呼規則

介面用語：**繁體中文**。  
性質：文案／文件用詞約定（非業務政策正文）。  
索引：[`OPS_POLICIES.md`](OPS_POLICIES.md)、[`AGENTS.md`](../AGENTS.md)。

**整理：** 2026-08-01

---

## 1. 正式名稱與機構自稱

| 用途 | 用 | 不用 |
| --- | --- | --- |
| 企業正式名稱／品牌露出（側欄、登入、頁標題、WhatsApp、收據抬頭） | **明學教育** | **明學補習社**、明學院、本院 |
| 英文品牌名 | **MainHope**（可寫 Main Hope 於法律／收據全大寫場合） | **mingxue**、MingXue、Ming Xue（非官方英文品牌） |
| 指「我們這一方／管理層／政策來源」 | **校方** | **院方** |
| 泛稱業務形態／口語 | **補習社**（例：呢間補習社） | 用「明學補習社」當正式名 |
| 指本校範圍／本社 | **本校**（例：本校停課日、本校校曆） | **本院**、**全院** |
| 場地內 | **校內** | **院內** |
| 全社範圍 | **全校**（例：全校停課日） | **全院** |

**法律全稱（收據等）：** 明學教育有限公司 MAIN HOPE EDUCATION LTD.（見 `paymentPrint`）。

**優先說明：**

- 對外／系統品牌字一律 **明學教育**；英文品牌 **MainHope**，唔好寫「明學補習社」或 mingxue。
- 政策文件寫「規條、口頭規矩」→ **校方**。
- 指本社場所或本社安排 → **本校**／**補習社**（視語境），唔用書院／學院。
- 程式套件／資料夾若仍見 `mingxue-admin` 等舊識別字，屬歷史技術名，**唔代表**英文品牌。

---

## 2. 禁止用「書院／學院」自稱

| 規則 | 說明 |
| --- | --- |
| **禁用** | 專案 UI、阿Po、文件、訊息**不得**用「書院」「學院」稱呼明學本身（含舊稱「學院校曆」） |
| **唯一例外** | 學生就讀的**中學正式校名**（英華書院、拔萃女書院、喇沙書院等） |

功能改名對照：

| 舊（禁用） | 新 |
| --- | --- |
| 學院校曆 | **校曆**（路由仍為 `/AcademicCalendar`） |
