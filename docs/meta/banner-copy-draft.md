# 橫旗文字修改草稿

計糧橫旗不在這次範圍。計糧頁面已更新，第 18–22 則已刪去，程式沒有改計糧。

有「cfan建議」的，以該段為準。沒有的，以「建議」為準。顏色、圖示、停留時間仍留到下一輪。

寫法：

- 標題要能單獨看懂。第二句要點開才出現，成功橫旗約 2 秒收起。
- 還有必做的下一步時，寫進標題。
- 用畫面用語：收款登記、已繳堂數、退讀。不用「權益池」「收款／出單」「退班」「到課宣告」。
- 正式操作不寫「示範」。
- 針對一位學生的結果，標題或第二句帶姓名。

按鈕字由 `前往` + 頁面名稱 + `頁面` 組成。例如頁面名稱寫「收款登記」，畫面上是「前往收款登記頁面」。

### 15. 報讀已寫入，但之後的堂未排好

目前標題（三種）：

- 報讀已寫入，但到課宣告未能完成
- 報讀已寫入，但未能結束未結案試堂
- 報讀已寫入，但未能結束未結案試堂，且到課宣告未能完成

另外三句：

- 報讀形式已更新，但到課宣告未能完成
- 選堂已更新，但到課宣告未能完成
- 排程已寫入，但到課宣告未能完成

- 報讀已寫入，但之後的堂未排好

- 報讀已寫入，但試堂未結束，之後的堂也未排好

## 一句裡塞了幾件事



### 23. 收款：確認作廢成功

情境：作廢對話按確認，單據已作廢，而且不是「本來就已作廢」。這次仍是一則橫旗，只把第二句拆短。「此單據已作廢」那一則不改。

目前標題：單據已作廢

目前第二句是下面幾段接在一起：

- 已電郵通知管理層。
- 或：通知未送出：｛原因｝
- 或：待繳單據作廢，未寄管理層電郵。
- 然後一定有：請檢查該生報讀與堂數對帳是否仍正確；作廢不自動退班。
- 有學生時再加：金額錯請到收款登記重開正確單。

建議標題：單據已作廢

建議第二句：

- 已通知管理層時：已通知管理層。請核對這生的報讀與堂數；作廢不會自動退讀。
- 通知失敗時：通知未送出：｛原因｝。請核對這生的報讀與堂數；作廢不會自動退讀。
- 待繳單未通知時：這張是待繳單，沒有通知管理層。請核對這生的報讀與堂數；作廢不會自動退讀。
- 有學生時，上面再加一句：金額若有錯，請到收款登記重開。
