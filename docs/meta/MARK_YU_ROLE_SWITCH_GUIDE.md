# Mark Yu 雙身份使用指引

Mark Yu 的帳戶同時具有以下兩個操作身份：

- **專科班老師**：處理自己的班別、課堂、點名及老師日常工作。
- **管理層**：查看營運總覽與管理層報表（不含日常櫃台／點名／收款登記等行政操作）。

系統會按目前選擇的身份顯示功能及限制資料權限。請按照當刻工作的性質選擇身份。

## 如何切換身份

### 電腦版

1. 使用 `markyu@mainhope.edu.hk` 登入。
2. 在左側選單底部找到「目前操作身份」。
3. 選擇「專科班老師」或「管理層」。
4. 系統會返回首頁，並以新身份重新載入選單及資料。

若左側選單已收起，請先按選單上方的展開箭咀。

### 手機版

1. 登入後打開左上角的主選單。
2. 在選單底部找到「目前操作身份」。
3. 選擇需要的身份。
4. 系統會返回首頁，並套用新身份。

> 切換身份會離開目前頁面。若正在填寫表格，請先儲存資料再切換。

## 何時使用「專科班老師」

進行自己的教學工作時，請使用專科班老師身份。

主要功能包括：

- 查看「我的班別」及自己負責的學生。
- 查看自己的時間表及排程。
- 進行點名及更新出席紀錄。
- 查看及填寫教學紀錄。
- 查看自己的一對一學生。
- 預約空房。
- 查看及更新個人資料。
- 收件匣通知（排程／請假／點名提醒等）。

老師身份的資料範圍：

- 只會看到自己負責的班別、課堂及相關學生。
- 可更新獲准的課堂狀態及點名資料。
- 不可新增或刪除排程。
- 不可修改班別設定或自行為班別加入學生。
- 不可查看收費、全校學生名單及其他行政資料。

## 何時使用「管理層」

需要查看全校營運狀況、報表或管理層儀表板時，請切換至管理層身份。

主要功能包括：

- 營運總覽（管理層首頁）。
- 人數／報讀相關報表、中學出席統計等管理層可見報表。
- 收件匣（與管理層相關通知）。

管理層身份**不包含**日常行政操作，例如：

- 前台指引精靈、試堂登記、點名紙日常操作。
- 收款登記、作廢繳費、優惠折扣。
- 用戶帳戶管理、系統日志、外星人專用功能。

以上行政／系統功能只限「行政」或「外星人」身份；Mark Yu 的帳戶不具備該等身份。

## 建議使用方式

- 上課、點名、查看自己的學生：使用「專科班老師」。
- 查看營運總覽或管理層報表：使用「管理層」。
- 完成管理層檢視後，可切回老師身份，避免誤看或誤改不相關資料。
- 操作紀錄會按照當時使用的身份記錄，因此開始工作前應先確認身份。

## 常見問題

### 看不到身份選擇器

1. 確認登入電郵為 `markyu@mainhope.edu.hk`。
2. 重新整理頁面。
3. 登出後重新登入。
4. 若仍未出現，請聯絡系統管理員確認雙身份設定是否已部署。

### 切換後找不到原本的功能

不同身份會顯示不同選單。請查看「目前操作身份」，並切換至適合該工作的身份。若需要櫃台／收款／點名紙等日常行政，請改由具備「行政」身份的同事處理。

### 顯示「沒有獲授予所選身份」

系統拒絕了未授權的角色切換。請重新整理或重新登入；若問題持續，請聯絡系統管理員。

### 切換身份後未儲存的內容消失

切換時系統會返回首頁，未儲存的表格內容不會保留。下次請先完成儲存再切換。
