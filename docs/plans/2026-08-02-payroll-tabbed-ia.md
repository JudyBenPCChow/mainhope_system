## 1. 資訊架構（兩層）

### 1.1 財務工作台 — 頂層 Tab

| Tab | 內容 | 對應 first-time 痛點 |
| --- | --- | --- |
| **① 本月概覽** | 版本／截止；齊備度（硬紅／軟黃）；進度四格；異常摘要；「下一步」CTA | 「我該做什麼？」；齊備度硬軟不分 |
| **② 逐人審核** | 左：精簡名單（名＋已審未審，可收合）；右：該人明細（子 Tab，見 §1.2） | 主戰場；名單唔塞灰色細節 |
| **③ 調整與工時** | Cody WFH 申報；人手調整申請／狀態列表 | 從審核頁拆走，減干擾 |
| **④ 提交** | 提交前摘要；checklist（可自動勾）；全月提交；單人送核佇列總覽 | checklist 恐嚇感；提交係獨立一步 |

**各 Tab 共用頂列（細、常駐）**：月份選擇、狀態 Tag、重算、CSV／工資單。  
破壞性：換月、重算 → 確認 dialog（見 §3）。

**沙盒 banner**：降級為角落細標「示範數據」；移除術語清單同「非正式角色」字眼（正式上線後按真實角色入 view）。

**順序策略（已取態）**：用 **Tab（可跳步）**，唔用強制 wizard。概覽寫清四步；**硬阻擋**先真正鎖「提交」Tab 嘅全月送核。

### 1.2 逐人明細 — 右欄子 Tab

| 子 Tab | 內容 |
| --- | --- |
| **摘要** | 總額＋「薪酬來源」一行 breakdown（例：個人分成 $X ＋ 數學 pool $Y ＝ $33,600）；點擊可跳／切到對應子 Tab |
| **堂數** | 兩層類別／年級表；班與逐節（LessonCard 證據鏈預設收合） |
| **分成／證據** | SplitAuditPanel、ModeStreamsPanel、SalaryEvidencePanel（有先顯示） |
| **結算** | MPF、上月對照；標記已審／送出此人／申請調整 |

預設開 **摘要**。有異常時可喺「堂數」或「分成／證據」Tab 顯示 badge。

單人「送出此人」動作留喺 **結算** 子 Tab；佇列總覽放頂層 **④ 提交**。

### 1.3 管理層核實台 — 頂層 Tab

| Tab | 內容 |
| --- | --- |
| **① 概覽** | 總薪酬／實發／僱員／僱主強積金／異常／待調整；月份狀態說明 |
| **② 待核佇列** | 單人送核、人手調整、Cody 工時（財務申報時數唯讀 vs 管理層確認時數可編） |
| **③ 強制抽查** | 抽查項；須展開／滾到該人明細先可勾「已抽查」 |
| **④ 結算** | 核實並結算／退回財務；確認 dialog（結算後不可改） |

文案：「收下此人」→「確認此人無誤」或「核實」。

## 2. 首次體驗疊加（唔另開巨型 wizard）

1. **概覽首屏**：寫明  
   `齊備檢查 → 逐人審核 → 調整／工時 → 提交`  
   - 未齊備（硬）→ CTA「去處理齊備／異常」  
   - 齊備且有未審 → CTA「開始審核（未審 N 人）」→ 切 ②  
   - 可提交 → CTA「前往提交」→ 切 ④  
2. **術語**：該詞首次出現嘅 Tab 旁加 `?`（HC、扣堂、齊備度、母名單、分成池、代入／代出…）；一句 hover／點開解釋。  
3. **可點擊性**：概覽進度卡 hover＋「點此篩選／前往」；游標 pointer。  
4. **查證排程／點名**：沙盒標「示範（未接真頁）」；正式版接 Schedule／Attendance。

## 3. 互動閘門與提交

| 操作 | 行為 |
| --- | --- |
| 切換月份 | Confirm：將清除本月審核進度 |
| 重算 | Confirm：版本遞增並清空已審標記 |
| 管理層結算 | Confirm：列明結算後不可再改 |
| 提交 checklist | 系統自動勾可驗證項（如已審人數、硬阻擋已清）；人手只勾無法自動驗證項；聲明改中性：「我已覆核以上項目，並對提交的數字負責」 |
| 管理層抽查勾選 | 未展開該教師明細前不可勾完成 |
