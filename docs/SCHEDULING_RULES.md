## 1. 排程格網

每格 **75 分鐘**，每日 10 格（索引 0–9）：

| 索引 | 時段 |
| --- | --- |
| 0 | 09:00–10:15 |
| 1 | 10:15–11:30 |
| 2 | 11:30–12:45 |
| 3 | 12:45–14:00 |
| 4 | 14:00–15:15 |
| 5 | 15:15–16:30 |
| 6 | 16:30–17:45 |
| 7 | 17:45–19:00 |
| 8 | 19:00–20:15 |
| 9 | 20:15–21:30 |

**硬約束：唔排 slot 9（20:15–21:30）。** 最遲一節為 **19:00–20:15**（slot 8）。平日與週末皆同。

## 3. 年級 × 時段（平日 vs 週末）

### 3.1 平日（星期一至五）

| 年級 | 最早可排 |
| --- | --- |
| 初中 **S1–S3** | **slot 6+**（16:30 起） |
| 高中 **S4–S6** | **slot 7+**（17:45 起） |

### 3.2 週末（星期六、日）

- 年級不限最早時段（仍受 §1 禁 slot 9、老師／課室／不撞科約束）。
- 週末宜預留空檔俾日後術科／副科；核心科（中英數）亦可排。

## 4. 功課輔導（功輔）

產品規格詳見 [`backlog/homework-tutoring.md`](backlog/homework-tutoring.md)。排課時以本節為硬約束摘要。

| 項目 | 規則 |
| --- | --- |
| 日子 | **星期一至五**（常規學期九月至六月；功輔校曆可與專科不同，放假日另表） |
| 營運時段 | 約 **15:30–19:30**；**課室佔用由 15:15 起**（對應格網約自 slot 5 起須預留該室） |
| 課室 | **非固定**某一房；平日通常將其中一室列為功輔專用，具體房號按月／按日編排 |
| 含義 | 已編作功輔之課室＋時段，**不可**再排常規專科班 |
| 末節讓房 | 有時約 **19:00–20:30** 一段可撥予專科（**規則待定**，見功輔 backlog C2） |
| 學生堂次 | 功輔為按月繳費，**不**按學生「逢星期幾」排堂／扣堂 |

## 5. 全校硬約束（老師節奏）

| 規則 | 說明 |
| --- | --- |
| **禁末節** | 唔排 20:15–21:30 |
| **連堂上限** | 同一老師最多連續 **2** 堂，之後必須空至少 **1** 格 |
| **全日上限** | 同一老師同一日最多 **5** 節 |
| **兼職密排** | 除全職外：同一日**相鄰兩堂之間最多空 1 格**（唔好隔兩格或以上先再上）。兼職上完應可盡快離開 |
| **全職空檔** | 目前僅 **Katie** 按全職處理——允許較大空檔（可做行政）。其餘老師（含 Mark、Christine、Cyndi、Jackson、TBD）一律兼職密排 |

**設計意圖：** 一節休息通常夠；中間太多空檔對兼職係浪費時間。全職可利用空檔做行政。

## 6. 不重疊與學生可多報

### 6.1 資源不撞（必須）

- 同一**老師**同時段不能教兩班
- 同一**課室**同時段不能有兩班
- 同一**年級**不同**科目**不能同一時段（否則學生無法同時報讀兩科）

例：S1 中文與 S1 數學不可同在星期一 slot 6。

### 6.2 同日順接（盡量）

同一年級同一日宜有不同科目**連續時段**順接，方便同日連上。  
例：S1 星期一 slot 6 中文 → 7 數學 → 8 英文。

### 6.3 每級日子分佈（盡量）

每級中英數宜分佈在 **2–3 個不同日子**，唔好全日集中一日。
