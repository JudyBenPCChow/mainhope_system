# 明學教育｜代堂與換主責老師守則

**適用對象：** 前台、行政及須安排課堂老師的前線同事  
**性質：** 校方營運規則說明（供日常執行）  
**機構名稱：** 明學教育（英文品牌 MainHope）

工程／資料模型細節見 [`../SCHEDULE_SUBSTITUTE_TEACHER.md`](../SCHEDULE_SUBSTITUTE_TEACHER.md)。

---

## 1. 本指引目的

本指引說明何時應使用**代堂**、何時應**換班別主責老師**，以及系統操作上必須遵守的禁則，方便前線同事：

- 正確記錄「邊位老師實際上堂」；
- 避免誤改主責而影響「我的班別」、報讀及日後計糧；
- 處理連堂、撞堂、改錯代堂等常見情況。

本指引為前線完整說明，閱讀時無須先參閱其他內部文件。

---

## 2. 一句話總則

**班別記常任老師；每一堂排程記當日實際上堂老師。**  
偶發由其他人上課 → 只做**代堂**。  
該班以後都改由另一位老師負責 → 先**換主責**（同一班、同一批學生）。  
勿用「改主責」代替「代一兩堂」；亦勿為代堂而新建另一班。

---

## 3. 兩個必須分清的概念

| 名稱 | 意思 | 前線應理解為 |
| --- | --- | --- |
| **班別主責老師** | 該班的常任負責老師 | 「呢班平時係邊位教」；影響老師端「我的班別」 |
| **當日授課老師** | 該堂排程上的老師 | 「呢一堂實際上係邊位上」；點名、時間表、計糧人頭以此為準 |

代堂時：主責通常不變，只改**該堂**的當日授課老師。  
換主責時：班的常任老師變更；**未來**尚未代堂的排程應跟新主責；**已經上過的堂**不應被改寫成新老師。

---

## 4. 何時代堂？何時換主責？

### 4.1 應使用「代堂」

同時符合下列情況時，用代堂：

| 情況 | 例子 |
| --- | --- |
| 只係個別日子由其他人上 | 主責請假、會議、臨時調動 |
| 同一班多日輪流上、但常任仍清晰 | 兩位老師按日輪替，班主責維持較常負責者 |
| 事後補記「當日邊位上」 | 歷史堂次補錄實際老師 |

### 4.2 應使用「換主責」

| 情況 | 說明 |
| --- | --- |
| 該班以後長期由另一位老師負責 | 學生、時段、班別本身不變，只換常任老師 |
| 一對一更換負責老師 | 系統會同步未取消排程（見第 6 章） |

換主責後：**無須**為同一批學生停舊班再開新班，學費／報讀留在原班，避免堂數對帳混亂。

### 4.3 應開新班（不是代堂，也不是單純換主責）

| 情況 | 說明 |
| --- | --- |
| 上課時段或班別安排實質改變 | 例如由週三改週六、班型變更 |
| 學生組合或班別產品改變 | 屬轉班，須另辦報讀；已繳堂數按原班對帳，不會自動轉去新班 |

### 4.4 切勿這樣做

| 錯誤做法 | 後果 |
| --- | --- |
| 為代一兩堂而改班別主責 | 「我的班別」、通知對象錯亂；歷史語意不清 |
| 為換老師而強制全班退讀再開新班 | 已繳／待補／請假未補須人手搬運，易錯 |
| 已點名後「取消代堂」圖方便改回 | 系統上會變成原老師上過，計糧／出勤失真 |
| 未指定班別負責老師就批量排程 | 老師時間表／點名紙可能看不到該堂 |

---

## 5. 代堂：前線步驟與守則

### 5.1 正確步驟

1. 確認該班**已有主責老師**（未有主責應先指定，再處理代堂）。  
2. 在**排程管理**或排程詳情，對該堂選「指派代堂」（若已代堂則「更改代堂」）。  
3. 選擇當日實際授課老師。  
4. 若系統提示該老師同一時段另有課堂（撞堂），先核對時間表；確認無誤後方可繼續。  
5. 由**當日授課老師**完成點名（原主責通常可查看，但不應代替點名，除非校方另有安排）。

### 5.2 連堂

連堂必須**整組一併代堂**（兩節同時改為同一代堂老師）。  
不可只代其中一節而留下另一節給原老師——系統亦不支援分節代堂。

### 5.3 更改代堂與取消代堂

| 情況 | 做法 |
| --- | --- |
| 尚未點名，想改代堂老師 | 用「更改代堂」 |
| 尚未點名，改回原主責上堂 | 可用「取消代堂」 |
| **已經點名** | **禁止取消代堂**；若當日老師記錯，用「更改代堂」改為正確老師 |
| 月結／計糧已處理後才發現錯誤 | 勿自行改歷史；按第 8 章異常處理呈報 |

### 5.4 代堂與學費

代堂**不改變**學生報讀班別，亦不改變該科已繳／已扣堂數。  
家長學費對帳仍按原班別（一科）計算，與誰代堂無關。

---

## 6. 換主責：前線步驟與守則

### 6.1 正確步驟（小組課／一對一原則相同）

1. 確認屬「長期更換常任老師」，而不是短時間代課。  
2. 在班別資料將**主責老師**改為新任老師並儲存。  
3. **一對一**：系統會同步未取消排程的負責老師（已有代堂的堂次會保留代堂老師，只更新「原任」記錄）。  
4. **小組課**：以營運要求為準——應只影響**未來**課堂的當日老師；已經上過的堂必須保留當時實際老師，不可一律改成新主責。  
5. 通知舊主責與新主責（系統或日常渠道），避免雙方以為班仍屬自己／不屬自己。

### 6.2 換主責之後預期現象

| 項目 | 預期 |
| --- | --- |
| 學生報讀、已繳堂數、點名歷史 | 留在同一班，無須轉班 |
| 舊主責「我的班別」 | 不再顯示該班 |
| 新主責「我的班別」 | 會顯示該班 |
| 已過去、已點名的堂 | 仍顯示／歸屬當時的當日授課老師 |
| 未來未代堂的堂 | 應顯示新主責為當日老師 |

### 6.3 換主責不能代替代堂

若只是本週由同事頂一堂，**必須代堂**，不要換主責。  
換主責會改變班的長期歸屬，影響面遠大於單堂代課。

---

## 7. 撞堂提示

指派代堂時，若系統警告代堂老師同一時間另有課堂：

- **可以**在核實後按確定繼續（例如人手已知其中一堂取消、或屬特殊安排）；  
- **不可以**在未核對時間表的情況下忽略警告。

責任在安排同事：確保該老師實際上能出席該堂。

---

## 8. 異常處理（須呈報）

下列情況屬程序錯誤或特殊個案，前線**不要自行改數了事**，應向主管／財務呈報：

| 情況 | 說明 |
| --- | --- |
| 已點名後發現代堂老師錯 | 優先「更改代堂」；若涉及已出糧或月結，一併呈報 |
| 已計糧／已結算後才改代堂或主責 | 屬異常；薪酬不自動重算，須人手調整並留紀錄 |
| 誤把短時代課做成換主責 | 呈報後按指示還原或補正，勿再疊加操作 |
| 排程有日期時間但沒有老師 | 行政以上應盡快補主責或指定該堂老師；未補前老師端可能看不到該堂 |

| 事項 | 入口 |
| --- | --- |
| 指派／更改／取消代堂 | 排程管理、排程詳情 |

## 10. 常見問答

**Q1：兩位老師輪流上同一班，要不要一直換主責？**  
A：不要。主責維持一位常任；非主責的日子用代堂標明當日老師。

**Q2：代堂老師在「我的班別」看不到該班，是否系統故障？**  
A：不是。代堂老師應從時間表或排程進入當日課堂；班列表只顯示主責班。

**Q3：換主責後，家長已交的學費會不會消失？**  
A：不會。同一班換主責不影響該科已繳堂數。

**Q4：連堂可否只代第二節？**  
A：不可。連堂必須整組代堂。

**Q5：已點名可否取消代堂？**  
A：不可。應使用更改代堂；涉及計糧問題按第 8 章呈報。

## 11. 一句話複習

> **代堂改「嗰一堂邊個上」；換主責改「呢班以後邊個負責」。已點名唔好取消代堂；短假唔好改主責；人頭同點名跟當日排程老師。**
