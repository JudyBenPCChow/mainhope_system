# 功輔當值改動通知（電郵）

當用戶**明講要執行／寄出**時，向本月當值有調整的老師各寄一封。文案用繁體中文書面語；術語跟 `.cursor/rules/terminology.mdc`。

無 MCP `execute_sql`／`supabase db query --linked`：**停、通知**。見 `no-forced-output-without-access.mdc`。金鑰未就緒：**停**。見 `agent-mail.mdc`。不要用舊對話名單充當今日編更。

## 何時用

用戶說：**執行**功輔當值通知、寄當值更新、通知當值有改的老師、發送功輔當值電郵。

只預覽、未說執行／寄出 → 組文列出涉及老師與正文，**不要寄**。

## 涉及老師

**涉及**＝該月相對**基準快照**，至少有一項當值變動：

| 變動 | 標記 |
| --- | --- |
| 新增一節 | `*新增` |
| 同日同學部時段改了 | `*修改︰由{舊開始}-{舊結束} 修改至 {新開始}-{新結束}` |
| 同學部改日／改學部（當舊格消失＋新格出現） | 舊行 `*取消`；新行 `*新增`（或能對上則用修改） |
| 整節刪除／改為暫時空缺 | `*取消`（該行仍列出原時段與學部） |

課室改名但時段／學部不變 → **不**算涉及（唔寄）。

無人有變動 → 回覆一句「無人需通知」，唔寄。

## 基準快照

路徑：`docs/generated/2627/2627_HOMEWORK_DUTY_<YYYY-MM>_notify_baseline.json`

結構見 [queries.md](queries.md)。優先序：

1. 已有 `*_notify_baseline.json` → 用作舊狀態。
2. 本對話剛改過當值且能重建改前狀態 → 用該狀態作基準（改完後仍應寫入 baseline，方便下次）。
3. 否則有 `2627_HOMEWORK_DUTY_<YYYY-MM>_HWKS.json`＋`_HWKP.json` 且確定係改前產出 → 可合併作基準。
4. 仍無基準 → **停**，問用戶：先存目前編更作基準，或確認「首次全量」寄給當月所有有當值老師（每人一封、無 `*新增／修改／取消`）。

寄出成功後，把**今次 production 現況**覆寫進 `*_notify_baseline.json`（唔 commit，除非用戶要發佈）。

## 步驟

1. **月份**：用戶指定 `YYYY-MM`；否則香港今日所在月（夾在 `2026-09`～`2027-06`）。
2. **查現況**：`execute_sql`／`db query --linked`，SQL 見 [queries.md](queries.md)。班別：`2627-HWKS1099-A`（中學部）、`2627-HWKP1099-A`（小學部）。
3. **載入基準**，按老師 diff（鍵：`teacher_id`；比對 `duty_date`＋`division`＋`start`＋`end`）。
4. **只處理涉及老師**。每人組**該月完整現況表**（含無改動日子），在有變動的行加標記；已取消但仍要交代的日子用 `*取消` 行補上。
5. **已完成**：香港今日之前的當值日，或當日且 `session_end` 已過 → 行末加`（已完成）`（標記放在學部之後、`*` 註之前）。
6. **收件**：正式寄 `teachers_private.notification_email`；無則跳過並在行政摘要註明。測試／模擬：只寄用戶指定信箱，不要寄老師本人。每封固定 **CC**（不是 BCC）：`cfan@mainhope.edu.hk`、`markyu@mainhope.edu.hk`。
7. **寄信**：優先 MCP `mainhope-mail` `send_email`；MCP 不可用則：

```bash
node scripts/mcp/resend-mail-server.mjs --status
node scripts/mcp/resend-mail-server.mjs --send \
  --to "<notification_email>" \
  --cc "cfan@mainhope.edu.hk" \
  --cc "markyu@mainhope.edu.hk" \
  --subject "<主旨>" \
  --text "<正文>"
```

8. 覆寫 baseline；回覆行政摘要（已寄／缺電郵／無變動）。

## 稱謂與主旨

- 顯示名：`english_name` 優先，否則 `full_name`。
- 稱謂：有把握用 `Ms.`／`Mr.`；否則 `Mr./Ms.`（與明日課堂提醒一致）。
- 主旨固定格式（只換月份中文名＋當事人稱謂與姓名；稱謂與名之間**無空格**）：

```
【更新】十月功輔班當值更表更新（Ms.Rain Kwok).
```

  - 全形前括號 `（`、半形後括號 `)`、句末半形句號 `.`
  - 例：Rain → `【更新】十月功輔班當值更表更新（Ms.Rain Kwok).`；Liam → `【更新】十月功輔班當值更表更新（Mr.Liam Lai).`
- 正文月份用語寫「十月份」這類（由 `YYYY-MM` 轉中文月名＋「份」）；主旨用「十月」不加「份」。

## 電郵正文（勿改骨架）

正文只用以下結構；只換稱謂、月份、當值行。日期不補零（`10月5日`）。時間主欄用 en dash `–`；`*修改` 括註內用半形連字號 `-`（跟用戶範本）。學部前用全形空白 `　`。

```
【以下為系統自動生成提醒，請勿回覆本電郵。】

Ms. Rain Kwok,

以下是您在系統中十月份最新的功輔班當值時間表，請核對是否有誤︰

10月5日 15:30–20:00　中學部（已完成）
10月6日 17:45–20:00　小學部（已完成）*修改︰由18:00-20:00 修改至 17:45-20:00
10月8日 15:30–20:00　小學部（已完成）
10月12日 15:30–20:00　中學部（已完成）
10月13日 17:30–20:00　中學部（已完成）
10月15日 15:30–20:00　中學部
10月20日 17:45–20:00　小學部 *修改︰由18:00-20:00 修改至 17:45-20:00
10月22日 15:30–20:00　中學部
10月26日 15:30–20:00　中學部 *新增
10月27日 17:45–20:00　小學部  *修改︰由18:00-20:00 修改至 17:45-20:00
10月29日 15:30–20:00　中學部

如時間日期有誤，請直接聯絡Christine Fan。

明學教育
```

（上例時段為假資料，只供格式；真寄必須用庫內現況＋真實 diff。）

排序：同一人按日期、開始時間、學部（中學部先於小學部）。

## 行政摘要（對話回覆）

列出：月份、基準來源、涉及老師數、每人變動摘要（新增／修改／取消幾項）、已寄信箱（可遮掩中段）、CC 兩址、跳過（無 `notification_email`）。不要把全文再貼一大輪，除非用戶要預覽。

## 勿做

- 未說執行／寄出就真寄
- 向無變動老師寄信（首次全量除外，且須用戶確認）
- 用舊 JSON 充當今日 production（比對基準除外）
- commit `docs/generated/**` 或讀出 `.env.mail` 金鑰
- 改發件人（固定 `noreply@mainhope.edu.hk`）
- 漏 CC 或改用 BCC；漏改主旨裡的當事人姓名
