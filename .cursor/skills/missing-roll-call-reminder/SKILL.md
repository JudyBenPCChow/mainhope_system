# 未點名提醒

以各人作為單位，每人一則。給同事轉發老師。文案用繁體中文書面語，用詞跟 `.cursor/rules/terminology.mdc`。

無 MCP `execute_sql`：**停、通知使用者**。不要用對話裡的舊名單充當今日結果。見 `.cursor/rules/no-forced-output-without-access.mdc`。不要代寄；用戶另給收件地址並明講寄出，才用 `mainhope-mail`。

## 何時用

用戶說：**未點名提醒**、**未提名提醒**、補點名提醒、再出一次提醒、各人一段。

## 步驟

1. 月份：用戶指定用該曆月；無指定用香港今日所在曆月。起日為該月 1 日；迄日為香港今日（只計已下課）。
2. `project_id` 取專案 `.mcp.json` 的 `project_ref`。讀 [queries.md](queries.md)，把月份起迄代入後 `execute_sql`。每次都重查，不要沿用上一則的名單。
3. 只計已下課、未取消、點名紙有人、該 `schedule_id` 沒有 `attendance_details` 的堂。今日未下課不計。空班不計。測試班、老師名或班號含 Test／HWKP 不計。已取消（含老師病假）不計。
4. 老師用該堂 `schedules.teacher_id`（代堂後的實際授課老師）。
5. 對話貼文用「系統訊息」。用戶要求寄電郵時，改用「電郵通知」，並另寫一封「行政總結」。測試時只寄用戶指定的老師與行政總結，收件地址用用戶給的信箱，不要寄去老師本人。

## 文案

每人一則，則與則之間空一行。時間寫 `HH:mm`。課程名稱用 `course_name`，括號內用完整 `course_code_full`。日期不補零（10月9日）。每堂獨佔一行，行末句號。結語不要改寫。

首行是一行：`【系統訊息】`、姓名、堂數摘要。其後空一行，再逐堂分行，再空一行，最後結語。

```
【系統訊息】 Elaine Yao老師︰ 您於10月1日至12日有 3 堂尚未點名

10月10日 12:45–14:00 中四級常規M2班（2627-M2S4001-B）。
10月11日 12:45–14:00 中四級常規M2班（2627-M2S4001-B）。
10月11日 14:00–15:15 中五級常規M2班（2627-M2S5001-A）。

請盡快於「進行點名」補點。未點名不會自動計算入人工之內。
```

`10月1日至12日` 換成今次計入的起迄日；姓名、堂數、課堂行換成該人實際資料。只有一堂時，課堂仍獨佔一行。

排序：未點堂數由多到少；同數按姓名。同一人的堂按日期、開始時間。

回覆先一行寫範圍（計至哪一日、幾人幾堂），再貼各則。該期間沒有人則只寫這一句，不要空則。

## 電郵通知

寄出時不用「系統訊息」那則。每人一封。主旨是 `十月尚未點名提醒（Ms. Elaine Yao)`：全形前括號、半形後括號；稱謂用該老師的 `Ms.` 或 `Mr.`。正文稱呼固定寫 `Mr/Ms. {英文姓名},`。正文只用下面句子，只換姓名、查庫時間、節數、課堂行。節數用中文（一、兩、三…）。查庫時間寫香港時間「上午／下午H:MM」（18:43 寫下午6:43）。課堂不編號。

```
主旨：十月尚未點名提醒（Ms. Elaine Yao)

Mr/Ms. Elaine Yao, 

根據系統10月12日下午6:00的資料，本月閣下尚有三節課堂未進行點名︰

10月10日（星期六）12:45–14:00　中四級常規M2班（2627-M2S4001-B）
10月11日（星期日）12:45–14:00　中四級常規M2班（2627-M2S4001-B）
10月11日（星期日）14:00–15:15　中五級常規M2班（2627-M2S5001-A）

煩請閣下盡快於「進行點名」進行點名，如你已經完成點名，則無須理會本電郵。

為確保上堂紀錄準確，我們建議你每次完成課堂後即時進行點名。

明學教育

(以上乃系統發出之提醒，切勿回覆本電郵）
```

## 行政總結

與老師個別信分開，另成一封。主旨固定為 `系統報告︰十月尚未點名紀錄報告`（全形冒號）。正文只用下面句子，只換日期與兩條橫線之間的老師課堂。橫線照抄。老師按未點節數由多到少，同數按姓名；每人先寫姓名，其下每堂一行，人不與人之間空一行。末句「系統已同步發送…」只在個別提醒確已寄出各老師通訊電郵時才寫；今次只是預覽、未寄給老師，則不要寫成已經寄出。

```
主旨：系統報告︰十月尚未點名紀錄報告

前台／行政同事︰

截至10月12日資料庫顯示，以下老師尚未完成點名。
－－－－－－－－－－－－－－

Elaine Yao
10月10日（星期六）12:45–14:00　中四級常規M2班（2627-M2S4001-B）
10月11日（星期日）12:45–14:00　中四級常規M2班（2627-M2S4001-B）
10月11日（星期日）14:00–15:15　中五級常規M2班（2627-M2S5001-A）

－－－－－－－－－－－－－－
系統已同步發送點名提醒至各老師之通訊電郵帳號。

(以上乃系統發出之提醒，切勿回覆本電郵）
```
